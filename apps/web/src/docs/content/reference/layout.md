# Макет листа (`layout`)

Контракт живёт в `packages/shared/src/schema/layout.ts` и `rich-text.ts`; им же
пользуются редактор, превью и серверный PDF-рендер. Здесь описано то, что принимает
`PATCH /api/documents/{id}/sheets/{sheetId}` в поле `layout`, — по Zod-схеме
`sheetLayout`. Текущая версия схемы — `schemaVersion: 2`; сервер проставляет её сам
при каждом сохранении макета.

Макет — **массив элементов** (не больше 500). Каждый элемент различается полем `type`:
`text`, `image`, `qr`, `link`, `shape`. Поля, у которых есть значение по умолчанию,
можно не передавать — сервер подставит их и сохранит уже нормализованный объект.

## Общие поля любого элемента

Координаты и размеры — в миллиметрах от левого верхнего угла листа.

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `id` | string | да | 1–100 символов. Уникальность в пределах листа сервер не проверяет, но редактор опирается на неё |
| `type` | `text` \| `image` \| `qr` \| `link` \| `shape` | да | Вид элемента |
| `x` | number | да | от −5000 до 5000 |
| `y` | number | да | от −5000 до 5000 |
| `w` | number | да | > 0, не больше 5000 |
| `h` | number | да | > 0, не больше 5000 |
| `rotation` | number | нет | −360…360, по умолчанию 0 |
| `z` | integer | нет | порядок наложения, −10000…10000, по умолчанию 0 |
| `opacity` | number | нет | 0…1, по умолчанию 1 |
| `locked` | boolean | нет | замок от сдвига в редакторе; печатается всё равно. По умолчанию `false` |
| `hidden` | boolean | нет | скрытый элемент не печатается и не виден на холсте. По умолчанию `false` |
| `groupId` | string \| null | нет | до 100 символов; элементы с одним `groupId` двигаются вместе. По умолчанию `null` |
| `name` | string \| null | нет | до 100 символов, подпись в панели слоёв. По умолчанию `null` |
| `props` | object | да | Свойства, зависящие от `type` — ниже |

## `type: "text"` — текстовый блок

Текст блока — дерево `props.doc` (см. «Дерево текста» ниже). На вход также принимается
прежний вид — строка `props.text` с переменными `%name`; сервер превращает её в дерево
и сохраняет уже в новом виде. Нужно передать **хотя бы одно** из `text` и `doc`, иначе
400 «У текстового блока нет ни текста, ни дерева». Текст без оформления не длиннее
5000 символов («Текст блока длиннее 5000 символов»).

Стили ниже — оформление всего блока по умолчанию; марки внутри дерева накладываются поверх.

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `doc` | RichDoc | да* | дерево текста; *либо `text` |
| `text` | string | да* | до 5000 символов, только на входе; *либо `doc` |
| `fontFamily` | string | нет | 1–100 символов из букв, цифр, пробела, `' , _ -`. По умолчанию `PT Sans` |
| `fontSize` | number | нет | кегль в pt, > 0, не больше 500. По умолчанию 16 |
| `color` | string | нет | `#RRGGBB`, по умолчанию `#000000` |
| `align` | `left` \| `center` \| `right` \| `justify` | нет | по умолчанию `center` |
| `verticalAlign` | `top` \| `middle` \| `bottom` | нет | по умолчанию `middle` |
| `lineHeight` | number | нет | > 0, по умолчанию 1.2 |
| `letterSpacing` | number | нет | по умолчанию 0 |
| `bold`, `italic`, `underline` | boolean | нет | по умолчанию `false` |
| `uppercase` | boolean | нет | прописные оформлением, а не правкой данных. По умолчанию `false` |
| `strokeWidth` | number | нет | обводка букв, мм, 0…2. По умолчанию 0 |
| `strokeColor` | string | нет | `#RRGGBB`, по умолчанию `#ffffff` |
| `autoFit` | boolean | нет | уменьшать кегль, чтобы текст влез в блок. По умолчанию `false` |
| `padding` | number | нет | отступ от краёв блока, мм, 0…50. По умолчанию 0 |
| `background` | string \| null | нет | заливка блока `#RRGGBB`; `null` — прозрачный (по умолчанию) |
| `borderWidth` | number | нет | рамка блока, мм, 0…5. По умолчанию 0 |
| `borderColor` | string | нет | `#RRGGBB`, по умолчанию `#000000` |
| `shadow` | boolean | нет | мягкая тень под текстом. По умолчанию `false` |

### Дерево текста (`RichDoc`)

Формат совпадает с деревом ProseMirror/TipTap: `{type, attrs, content, marks}`.
Пределы на всё дерево: не больше 1000 узлов («В блоке больше 1000 узлов») и не глубже
6 уровней списков («Списки вложены глубже 6 уровней»).

```
doc
└── content: RichBlock[]          — paragraph | bulletList | orderedList
    paragraph
      attrs: { align: left|center|right|justify|null, indent: 0..8 }
      content: RichInline[]      — text | mergeField | hardBreak
    bulletList
      attrs: { marker: disc|dash|circle|square }      (по умолчанию disc)
      content: listItem[]
    orderedList
      attrs: { numbering: decimal-dot|decimal-paren|upper-roman|lower-alpha, start: 1..9999 }
      content: listItem[]
    listItem
      attrs: { checked: boolean|null }               (null — обычный пункт)
      content: RichBlock[]                            (снова абзацы и списки)
```

Строчные узлы:

| Узел | Поля | Описание |
|---|---|---|
| `text` | `text` (1–5000 символов), `marks?` | обычный прогон текста |
| `mergeField` | `attrs.source` (обязательно, `^[a-zA-Z][a-zA-Z0-9_]*$`, до 100), `attrs.fieldId?` (string \| null, до 100), `attrs.fallback?` (string \| null, до 200), `attrs.format` (`none` \| `upper` \| `lower` \| `title`, по умолчанию `none`), `marks?` | подставляемое поле: `source` — ключ в данных строки (колонка списка или служебная переменная), `fieldId` — стабильный идентификатор колонки (у макетов из старого текста его нет), `fallback` — что напечатать, если значения нет |
| `hardBreak` | `marks?` | перевод строки внутри абзаца |

`attrs` у `paragraph`, `bulletList`, `orderedList`, `listItem` можно не передавать —
подставятся значения по умолчанию.

Марки (`marks`, до 8 на прогон), различаются по `type`:

| Марка | Поля |
|---|---|
| `bold`, `italic`, `underline`, `strike`, `superscript`, `subscript` | только `type` |
| `textStyle` | `attrs`: `color?`, `background?` (`#RRGGBB`), `fontFamily?`, `fontSize?` (> 0, ≤ 500 pt), `fontWeight?` (integer 100…900), `letterSpacing?`, `wordSpacing?` (−20…100 pt), `transform?` (`uppercase` \| `lowercase` \| `smallcaps`). Все поля необязательны |
| `link` | `attrs.href` (обязательно, до 2000, шаблон `http(s)://…`, в нём допустимы поля `{{code}}` и `%site`), `attrs.underline` (по умолчанию `true`), `attrs.color?` (`#RRGGBB`) |

Ошибка адреса ссылки: «Ссылка должна начинаться с http:// или https://».

Минимальный текстовый блок с подстановкой имени:

```json
{
  "id": "name",
  "type": "text",
  "x": 20, "y": 90, "w": 257, "h": 20,
  "props": {
    "fontSize": 32,
    "bold": true,
    "doc": {
      "type": "doc",
      "content": [
        {
          "type": "paragraph",
          "content": [
            { "type": "text", "text": "Награждается " },
            { "type": "mergeField", "attrs": { "source": "name", "format": "none" } }
          ]
        }
      ]
    }
  }
}
```

То же самое в старой записи (сервер сохранит как дерево):

```json
{ "id": "name", "type": "text", "x": 20, "y": 90, "w": 257, "h": 20,
  "props": { "text": "Награждается %name", "fontSize": 32, "bold": true } }
```

## `type: "image"` — картинка

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `props.fileId` | UUID | да | Идентификатор файла организации. Отдельного эндпоинта загрузки картинок-элементов в этом контроллере нет: через API загружается только фон листа (`POST …/sheets/{sheetId}/background`), его `fileId` подойдёт |

## `type: "qr"` — QR-код

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `props.template` | string | нет | шаблон содержимого, до 5000 символов, с переменными `%name`. Пустая строка (по умолчанию) — адрес страницы проверки экземпляра |
| `props.color` | string | нет | `#RRGGBB`, по умолчанию `#000000` |

## `type: "link"` — кликабельная область

Невидимый прямоугольник, в PDF становится аннотацией-ссылкой.

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `props.url` | string | да | до 2000 символов, `http://` или `https://`, допустимы поля `{{code}}` / `%site`. Ошибка: «Ссылка должна начинаться с http:// или https://» |

## `type: "shape"` — фигура

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `props.kind` | `rect` \| `ellipse` \| `line` | нет | по умолчанию `rect` |
| `props.fill` | string \| null | нет | заливка `#RRGGBB`; `null` (по умолчанию) — без заливки |
| `props.stroke` | string | нет | `#RRGGBB`, по умолчанию `#000000` |
| `props.strokeWidth` | number | нет | мм, 0…20, по умолчанию 0.5 |
| `props.radius` | number | нет | скругление углов, мм, 0…100, по умолчанию 0 |
| `props.dash` | number | нет | длина штриха пунктира, мм, 0…50; 0 (по умолчанию) — сплошная |

## Переменные подстановки

Источник — `packages/shared/src/variables.ts`. Значения для подстановки — это колонки
таблицы получателей плюс служебные переменные; **колонка с тем же именем перекрывает
служебную переменную**.

Синтаксис: в дереве текста — узел `mergeField` с `source: "name"`; в строке `text`,
в `qr.template` и в адресах ссылок — `%name` (латиница, цифры, подчёркивание, начинается
с буквы); в адресах ссылок допустима и запись `{{name}}`.

Служебные переменные (подставляет сервис при выпуске):

| Имя | Что подставляется |
|---|---|
| `date` | дата выдачи, `04.08.2026` |
| `date_long` | `4 августа 2026 г.` |
| `date_iso` | `2026-08-04` |
| `date_en` | `4 August 2026` |
| `year` | год выдачи |
| `number` | номер строки по списку, с единицы |
| `total` | всего строк в списке |
| `reg_number` | регистрационный номер экземпляра, `142/2026` |
| `code` | проверочный код экземпляра (публичный идентификатор) |
| `org` | название организации из настроек кабинета |
| `valid_until` | дата окончания срока, если у материала задан срок |
| `event`, `event_date`, `event_place`, `hours` | поля мероприятия из карточки документа (`eventName`, `eventDate`, `eventPlace`, `eventHours`) |
| `name_dat`, `name_gen`, `name_short` | ФИО в дательном, родительном, сокращённо — считаются из `name` (или из колонок «Фамилия/Имя/Отчество») |
| `name_lat_gost`, `name_lat_icao` | ФИО латиницей по ГОСТ 7.79-2000 и по ICAO |
| `place_word` | место словом («первое») из колонки `place` |
| `hours_word` | объём часов прописью из `hours`, если там чистое число |

Дата выдачи берётся из `issueDate` документа, если задана, иначе — момент выпуска;
время — московское. Незаполненная переменная при печати превращается в пустую строку
(или в `fallback` узла `mergeField`).

## Размер листа

Задаётся не в макете, а у документа: `pageWidthMm` × `pageHeightMm` (50…600 мм каждая
сторона; по умолчанию 297 × 210 — A4 альбомный). Готовые форматы из
`page-sizes.ts`: A3 297×420, A4 210×297, A5 148×210, A6 105×148, US Letter 216×279,
US Legal 216×356, квадрат 210×210, экран 16:9 167×297 (книжные; альбомный — переворот сторон).
