# Коды проблем проверки списка

Возвращаются в `rows[].problems[].code` ответа `POST /api/documents/{id}/validation`. Источник — `packages/shared/src/validation/problems.ts` (`PROBLEM_KINDS`).

Серьёзность: `blocker` — печатать нельзя, получится брак или письмо не уйдёт; `warning` — печатать можно, но человек, скорее всего, ошибся. В `blocked` отчёта считаются строки хотя бы с одной проблемой уровня `blocker`.

| Код | Серьёзность | Название | Чем кончится, если не исправить |
|---|---|---|---|
| `overflow` | blocker | Не влезает в блок | Текст обрежется на печати — часть имени пропадёт с грамоты |
| `required_empty` | blocker | Пустое обязательное поле | На грамоте останется пустое место там, где должно стоять значение |
| `duplicate_name` | warning | Повтор ФИО | Один человек получит две грамоты, если это не тёзки |
| `duplicate_email` | warning | Повтор адреса почты | На один адрес уйдёт несколько писем |
| `email_invalid` | blocker | Неверный адрес почты | Письмо не уйдёт — документ придётся передавать вручную |
| `email_mixed_script` | warning | Русские буквы в адресе | Скорее всего, набрано в русской раскладке и письмо вернётся. У некоторых российских провайдеров такой адрес рабочий — проверьте |
| `date_invalid` | warning | Непонятная дата | На грамоте напечатается ровно то, что в ячейке |
| `name_uppercase` | warning | ФИО прописными | Прописные попадут на грамоту как есть — обычно так выгружают из протокола |
| `name_not_declined` | warning | Падеж не подобрался | В макете «награждается %name_dat», а имя останется в именительном |
| `already_issued` | warning | Уже выдавалось | Этому получателю по этому документу уже выпускали грамоту |

Поле `suggestion` у проблемы есть не всегда: `name_uppercase` и `email_mixed_script` чинятся однозначно и приходят с готовой заменой, `overflow` — правкой макета или руками.

Правила награждения (занятые места, группы) проверка пока не разбирает: `checkAwardingRules` возвращает пустой список, а в `caveats` отчёта всегда есть оговорка «Занятые места и правила награждения проверка не смотрела…».
