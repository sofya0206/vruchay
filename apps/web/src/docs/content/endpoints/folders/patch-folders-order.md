# PATCH /api/folders/order

Задаёт порядок папок в колонке. Место папки — это её номер в присланном
списке: первая получает позицию 0, вторая 1 и так далее.

Список принимается только целиком. Перетаскивание одной папки сдвигает все,
что стоят между старым и новым местом, поэтому «папка и её новый номер»
потребовали бы нескольких запросов на один жест, а обрыв связи посередине
оставил бы колонку в порядке, которого никто не выбирал.

## Запрос

| Параметр | Тип             | Обязателен | Описание                                                           |
| -------- | --------------- | ---------- | ------------------------------------------------------------------ |
| ids      | string[] (UUID) | да         | Все папки организации, в нужном порядке. 1…100 штук, без повторов. |

```json
{ "ids": ["8f1e…", "2b40…", "c7a9…"] }
```

## Ответ

`200 OK` — список папок в новом порядке, в том же виде, что у `GET /api/folders`.

```json
[
  { "id": "8f1e…", "name": "Спортивные соревнования", "position": 0, "count": 32 },
  { "id": "2b40…", "name": "Обучение и семинары", "position": 1, "count": 5 }
]
```

## Ошибки

| Код | Когда                                                                                                    |
| --- | -------------------------------------------------------------------------------------------------------- |
| 400 | Пустой список, больше ста папок, не UUID или одна папка названа дважды.                                  |
| 401 | Нет токена или cookie-сессии.                                                                            |
| 404 | В списке есть чужая папка или перечислены не все свои: «Папка не найдена». Порядок при этом не меняется. |

Неполный список — это тоже 404, а не частичная перестановка: расставить
половину папок нельзя, остальные встали бы на места, которых никто им
не назначал.

## Пример

```bash
curl -X PATCH "https://vruchay.ru/api/folders/order" \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"ids":["8f1e…","2b40…","c7a9…"]}'
```
