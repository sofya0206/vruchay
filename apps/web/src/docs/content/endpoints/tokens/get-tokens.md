# GET /api/tokens

Список действующих (не отозванных) токенов API организации, новые сверху. Сам токен в списке не показывается — только его начало (`prefix`, первые 10 знаков: `vru_` и шесть символов), по которому владелец узнаёт свой токен среди нескольких. Полный токен выдаётся один раз в ответе `POST /api/tokens` и нигде больше не хранится.

**По токену API недоступно, только из кабинета (cookie-сессия).** Токен не может ни видеть, ни выдавать, ни отзывать другие токены — иначе утёкший токен нельзя было бы отозвать: он тут же выдал бы себе следующий.

## Запрос

Параметров нет.

## Ответ

`200 OK` — массив.

| Поле | Тип | Описание |
|---|---|---|
| id | string (UUID) | Идентификатор токена — нужен для отзыва. |
| name | string | Название, заданное при выдаче. |
| prefix | string | Первые 10 знаков токена (`vru_` + 6 символов). |
| role | string | `member` или `admin`. |
| createdAt | string (ISO 8601) | Когда выдан. |
| lastUsedAt | string (ISO 8601) \| null | Когда токеном пользовались в последний раз. Отметка обновляется не чаще раза в час; `null` — не использовался ни разу. |

```json
[
  {
    "id": "5f1c2e6a-9d0b-4c3e-8a7f-1b2c3d4e5f60",
    "name": "выгрузка из СпортОрг",
    "prefix": "vru_Qm9yaX",
    "role": "member",
    "createdAt": "2026-08-30T09:12:44.000Z",
    "lastUsedAt": "2026-09-02T18:03:10.000Z"
  }
]
```

## Ошибки

| Код | Когда |
|---|---|
| 401 | Нет cookie-сессии. `{"statusCode":401,"message":"Требуется вход в систему","error":"Unauthorized"}` |
| 403 | Запрос пришёл по токену API: «Это действие доступно только человеку, вошедшему в кабинет. Токен API управлять сотрудниками не может.» |
| 403 | Роль `member`: «Недостаточно прав для этого действия». |

## Пример

```bash
curl "https://vruchay.ru/api/tokens" \
  -b cookies.txt
```
