# GET /api/documents/{id}/registry.csv

Тот же реестр, что `GET /api/documents/{id}/registry`, но таблицей под русский Excel:
разделитель — точка с запятой, кодировка UTF-8 с меткой порядка байтов, строки
разделены `\r\n`, каждая ячейка в кавычках. Значения, начинающиеся с `=`, `+`, `-`, `@`,
табуляции, предваряются апострофом — защита от выполнения формул.

Колонки: `№`, `ФИО`, `Адрес почты`, затем все остальные колонки таблицы получателей
(по фактическим данным, кроме `name` и `email`), `Выдан` (дата и время по Москве,
`19.06.2026, 15:00`), `Проверочный код` (в этой колонке — `publicId`), `Письмо`
(«не отправлялось», «в очереди», «отправлено», «доставлено», «прочитано»,
«не доставлено», «ошибка»).

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `id` | UUID | да | идентификатор документа |

Тела нет.

## Ответ

`200 OK`, файл.

- `Content-Type: text/csv; charset=utf-8`
- `Content-Disposition: attachment; filename="registry-<id>.csv"`

```
"№";"ФИО";"Адрес почты";"place";"Выдан";"Проверочный код";"Письмо"
"1";"Иванов Пётр Ильич";"ivanov@example.com";"1";"19.06.2026, 15:00";"f6a7b8c9-d0e1-4f2a-9b3c-4d5e6f7a8b9c";"доставлено"
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | «Некорректный идентификатор» — `id` не UUID |
| 401 | нет токена или сессии |
| 404 | «Документ не найден» — нет такого, чужой или в корзине |

## Пример

```bash
curl "https://vruchay.ru/api/documents/$DOCUMENT_ID/registry.csv" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN" \
  -o registry.csv
```
