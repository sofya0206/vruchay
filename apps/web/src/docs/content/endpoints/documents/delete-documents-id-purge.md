# DELETE /api/documents/{id}/purge

Окончательное удаление документа, который уже лежит в корзине. Вместе с ним
уничтожаются все его файлы в хранилище и записи о них: фоны, картинки и **выданные
получателям документы** — ссылки проверки по ним перестают работать. Отменить нечем,
поэтому только владелец организации. Действие пишется в журнал (`document.purge`).

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `id` | UUID | да | идентификатор документа в корзине |

Тела нет.

## Ответ

`200 OK`

| Поле | Тип | Описание |
|---|---|---|
| `ok` | `true` | |
| `title` | string | название удалённого документа |

```json
{ "ok": true, "title": "Грамота за место" }
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | «Некорректный идентификатор» — `id` не UUID |
| 401 | нет токена или сессии |
| 403 | «Недостаточно прав для этого действия» — роль `admin` или `member` |
| 404 | «Документ не найден» — нет такого, чужой или ещё не в корзине |

## Пример

```bash
curl -X DELETE "https://vruchay.ru/api/documents/$DOCUMENT_ID/purge" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN"
```
