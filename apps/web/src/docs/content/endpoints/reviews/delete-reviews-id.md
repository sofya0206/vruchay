# DELETE /api/reviews/{id}

Убрать отзыв своей организации. Удаление окончательное: записи не остаётся,
и опубликованный отзыв пропадает с посадочной страницы. Чтобы просто переписать
текст, удалять ничего не нужно — достаточно `PATCH /api/reviews/mine`.

Удалить можно только собственный отзыв: перед удалением проверяется, что он
принадлежит организации из сессии. Роль не проверяется — убрать отзыв может
любой сотрудник.

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `id` | UUID | да | Идентификатор отзыва из `GET /api/reviews/mine`. |

Тела нет.

## Ответ

`200 OK`

| Поле | Тип | Описание |
|---|---|---|
| ok | boolean | Всегда `true`. |

```json
{ "ok": true }
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | `id` не UUID — «Некорректный идентификатор». |
| 401 | Нет действующего токена и нет cookie-сессии. |
| 404 | Отзыва нет или он принадлежит другой организации — «Отзыв не найден». Чужой отзыв отвечает 404, а не 403: иначе по ответу можно было бы узнавать, какие отзывы вообще существуют. |

## Пример

```bash
curl -X DELETE "https://vruchay.ru/api/reviews/$REVIEW_ID" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN"
```
