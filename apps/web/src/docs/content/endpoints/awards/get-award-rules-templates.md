# GET /api/award-rules/templates

Список документов организации, из которых выбирают шаблон для выхода правила (`outputs[].templateDocumentId`). Отдельного признака «шаблон» у документа нет: шаблоном может быть любой живой документ организации — тот, чьи листы будут выпущены получателям, попавшим под правило.

Отдаются не больше 200 документов, свежие по времени правки сверху; документы из корзины не показываются. Пагинации и поиска нет. Ссылка на документ другой организации или на удалённый документ при сохранении набора отклоняется — см. `POST /api/award-rules`.

## Запрос

Параметров пути и строки запроса нет. Тела нет.

## Ответ

`200 OK` — массив документов.

| Поле | Тип | Описание |
|---|---|---|
| `id` | UUID | идентификатор документа-шаблона |
| `title` | string | название документа |

```json
[
  { "id": "3a9e0c4d-3333-4c7d-8e1f-2a3b4c5d6e7f", "title": "Диплом победителя" },
  { "id": "4b0f1d5e-5555-4d8e-9f21-4c5d6e7f8091", "title": "Грамота участника" }
]
```

## Ошибки

| Код | Когда |
|---|---|
| 401 | Нет токена или сессии |

## Пример

```bash
curl "https://vruchay.ru/api/award-rules/templates" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN"
```
