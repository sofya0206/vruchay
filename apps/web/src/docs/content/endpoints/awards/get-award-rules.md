# GET /api/award-rules

Наборы правил награждения организации. Набор описывает, кому какой документ полагается по данным таблицы получателей: «первое место — диплом победителя», «снятым не выдавать», «остальным грамота участника». Набор принадлежит организации, а не соревнованию, — федерация настраивает награждение один раз на сезон и применяет к каждому следующему протоколу привязкой `POST /api/documents/{id}/awards/rule-set`.

Список короткий: сами правила здесь не отдаются, только их количество. Полный набор — `GET /api/award-rules/{id}`. Удалённые наборы (мягкое удаление) не показываются. Пагинации нет — отдаются все живые наборы организации.

Порядок: сначала набор по умолчанию, дальше по времени правки, свежие сверху.

## Запрос

Параметров пути и строки запроса нет. Тела нет.

## Ответ

`200 OK` — массив наборов.

| Поле | Тип | Описание |
|---|---|---|
| `id` | UUID | |
| `name` | string | название набора |
| `groupColumn` | string | колонка группировки, `""` — не выбрана |
| `statusColumn` | string | колонка статуса, `""` — не выбрана |
| `isDefault` | boolean | предлагать по умолчанию для нового соревнования; такой набор у организации один |
| `schemaVersion` | integer | версия формата правил, сейчас 1 |
| `updatedAt` | string (ISO 8601) | время последней правки |
| `ruleCount` | integer | сколько правил в наборе |
| `documentCount` | integer | к скольким документам набор сейчас привязан |

```json
[
  {
    "id": "7c1f7d1e-2b5e-4c3a-9c1a-8d2f0a6b1e11",
    "name": "Награждение по протоколу",
    "groupColumn": "category",
    "statusColumn": "status",
    "isDefault": true,
    "schemaVersion": 1,
    "updatedAt": "2026-03-02T09:14:00.000Z",
    "ruleCount": 3,
    "documentCount": 7
  }
]
```
