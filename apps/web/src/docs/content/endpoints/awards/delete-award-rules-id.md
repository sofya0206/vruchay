# DELETE /api/award-rules/{id}

Убирает набор из списка. Удаление мягкое: запись остаётся в базе с отметкой времени удаления, а признак «по умолчанию» снимается. Так сделано ради реестра выданного — он должен уметь объяснить, по какому правилу выдан документ на прошлом соревновании, даже когда набором больше не пользуются.

После удаления набор перестаёт отдаваться где бы то ни было: `GET /api/award-rules/{id}` вернёт 404, привязать его к документу уже нельзя. Привязка у документов, где набор был выбран, при этом не снимается сама — `POST /api/documents/{id}/awards/preview` без тела на таком документе ответит 404 «Набор правил не найден», пока не привязать другой набор.

Восстановления из корзины для наборов нет.

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `id` | UUID (путь) | да | Идентификатор набора правил |

Тела нет.

## Ответ

`200 OK`

| Поле | Тип | Описание |
|---|---|---|
| `ok` | boolean | всегда `true` |

```json
{ "ok": true }
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | `Некорректный идентификатор` — `id` не UUID |
| 401 | Нет токена или сессии |
| 404 | `Набор правил не найден` — нет такого, он уже удалён или принадлежит другой организации |

## Пример

```bash
curl -X DELETE "https://vruchay.ru/api/award-rules/$RULE_SET_ID" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN"
```
