# GET /api/jobs/{jobId}

Текущее состояние задания. Это тот запрос, которым следят за асинхронным
выпуском: после `POST /api/documents/{id}/generate` опрашивайте этот адрес,
пока `status` не станет закрытым — `done`, `failed` или `canceled`.
Прогресс — это `done` и `failed` против `total`; выпуск закончен, когда
`done + failed` дошло до `total`.

К записи задания добавлено вычисляемое поле `stuck`: задание может честно
стоять в очереди, а может стоять в ней навсегда, и по одному статусу `queued`
эти два случая не различить. Подробности признака и таблица «что разрешено
в каком состоянии» — в
[reference/generation-job.md](../../reference/generation-job.md).

Разумный шаг опроса — несколько секунд: воркер печатает примерно полсотни
документов в минуту и пересчитывает `done` после каждой строки.

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `jobId` | UUID (путь) | да | Идентификатор задания |

Тела нет.

## Ответ

`200 OK` — запись задания (см.
[reference/generation-job.md](../../reference/generation-job.md)) плюс одно поле:

| Поле | Тип | Описание |
|---|---|---|
| `stuck` | boolean | Задание стоит в очереди дольше 15 минут, ничего не начав. Такое принимается `POST /api/jobs/{jobId}/resume` |

```json
{
  "id": "5c8f1a2b-3d4e-4f50-8a6b-7c8d9e0f1a2b",
  "orgId": "1a2b3c4d-5e6f-4708-9a0b-1c2d3e4f5a6b",
  "documentId": "b1c2d3e4-f5a6-4b7c-8d9e-0f1a2b3c4d5e",
  "format": "pdf",
  "status": "running",
  "total": 128,
  "done": 74,
  "failed": 1,
  "error": null,
  "chunks": 3,
  "attempt": 1,
  "createdAt": "2026-06-15T09:12:44.000Z",
  "startedAt": "2026-06-15T09:12:51.000Z",
  "finishedAt": null,
  "stuck": false
}
```

Закрытое задание с неудачными строками выглядит так: `status` — `done`,
`failed` — сколько-то, `error` — `Не удалось создать файлов: 3`. Выпуск,
остановленный общей бедой, приходит со `status: "failed"` и объяснением
в `error` вида «Выпуск остановлен: хранилище файлов не отвечает. Созданные
документы сохранены, за остальные ничего не списано — когда причина
устранится, выпуск можно продолжить с того же места.»

## Ошибки

| Код | Когда |
|---|---|
| 400 | `Некорректный идентификатор` — `jobId` не UUID |
| 401 | Нет токена или сессии |
| 404 | `Задание не найдено` — нет такого или оно чужой организации |

## Пример

```bash
curl "https://vruchay.ru/api/jobs/$JOB_ID" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN"
```
