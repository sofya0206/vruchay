# POST /api/jobs/{jobId}/cancel

Отменяет остаток начатого выпуска. Разрешено только для активного задания —
`queued` или `running`; закрытое отменять нечего.

Уже созданные документы остаются: человек отказывается от остатка, а не от
сделанного. Их можно скачать тем же `GET /api/jobs/{jobId}/archive`. Квота за
ненапечатанные строки не списана — списывается она в момент создания файла,
а не при постановке задания; отменённое задание перестаёт быть активным,
и вместе с ним из расчёта уходит его бронь.

Отмена не мгновенная в том смысле, что часть, уже взятую воркером в работу,
прервать посреди отрисовки нельзя — иначе в хранилище остался бы файл, которого
нет в базе. Части, до которых воркер не добрался, снимаются с очереди сразу,
а работающая увидит отмену между строками и остановится. Поэтому `done` может
подрасти ещё на один-два документа после ответа.

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `jobId` | UUID (путь) | да | Идентификатор задания |

Тела нет.

## Ответ

`201 Created` — запись задания (см.
[reference/generation-job.md](../../reference/generation-job.md)) плюс одно поле:

| Поле | Тип | Описание |
|---|---|---|
| `refunded` | number | Сколько строк осталось необработанными: `total − done − failed`, но не меньше нуля. Столько квоты и не списалось |

```json
{
  "id": "5c8f1a2b-3d4e-4f50-8a6b-7c8d9e0f1a2b",
  "orgId": "1a2b3c4d-5e6f-4708-9a0b-1c2d3e4f5a6b",
  "documentId": "b1c2d3e4-f5a6-4b7c-8d9e-0f1a2b3c4d5e",
  "format": "pdf",
  "status": "canceled",
  "total": 128,
  "done": 74,
  "failed": 1,
  "error": null,
  "chunks": 3,
  "attempt": 1,
  "createdAt": "2026-06-15T09:12:44.000Z",
  "startedAt": "2026-06-15T09:12:51.000Z",
  "finishedAt": "2026-06-15T09:15:02.000Z",
  "refunded": 53
}
```

Отменённое задание остаётся продолжаемым: `POST /api/jobs/{jobId}/resume`
доделает его с того же места.

## Ошибки

| Код | Когда |
|---|---|
| 400 | `Некорректный идентификатор` — `jobId` не UUID |
| 400 | `Это задание уже завершено — отменять нечего` — статус не `queued` и не `running` |
| 401 | Нет токена или сессии |
| 404 | `Задание не найдено` — нет такого или оно чужой организации |

## Пример

```bash
curl -X POST "https://vruchay.ru/api/jobs/$JOB_ID/cancel" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN"
```
