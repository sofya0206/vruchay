# GET /api/org/usage

Сколько документов организация уже выпустила и сколько ещё может выпустить на бесплатной пробе. Полезно вызвать перед запуском выпуска: при нехватке лимита выпуск отказывает с 400, а здесь запас виден заранее.

Как считается:

- `used` — число выпущенных файлов организации за всё время (файлы вида `generated`), тем же способом, каким проверяется сам лимит. Удаление документа или файла из счётчика не вычитает; перевыпуск считается наравне с обычным выпуском.
- На тарифе `free` предел `limit` = базовая проба (`FREE_DOCUMENT_LIMIT`, по умолчанию 50) + `bonus` за приглашения: 50 документов, если организацию пригласили по коду, и по 50 за каждого приглашённого, который выпустил не меньше 10 документов (не больше 20 таких приглашённых). Значения задаются настройками сервера и могут отличаться от умолчаний.
- На тарифе `paid` предела нет: `limit` и `left` равны `null`, `bonus` — 0.

Обратите внимание: `left` не учитывает бронь незавершённых выпусков. Проверка при запуске выпуска прибавляет к `used` строки заданий в статусах `queued` и `running`, поэтому пока идёт выпуск, фактический запас меньше, чем показывает этот ответ.

## Запрос

Параметров нет.

## Ответ

`200 OK`

| Поле | Тип | Описание |
|---|---|---|
| plan | string | `free` или `paid`. |
| used | number | Выпущено документов за всё время. |
| limit | number \| null | Предел пробы с учётом бонусов. `null` на `paid`. |
| left | number \| null | Осталось: `max(0, limit − used)`. `null` на `paid`. |
| bonus | number | Документы сверх базовой пробы, заработанные приглашениями. На `paid` — 0. |

```json
{
  "plan": "free",
  "used": 37,
  "limit": 100,
  "left": 63,
  "bonus": 50
}
```

На оплаченном тарифе:

```json
{
  "plan": "paid",
  "used": 1240,
  "limit": null,
  "left": null,
  "bonus": 0
}
```

## Ошибки

| Код | Когда |
|---|---|
| 401 | Нет действующего токена и нет cookie-сессии. `{"statusCode":401,"message":"Требуется вход в систему","error":"Unauthorized"}` |

## Пример

```bash
curl "https://vruchay.ru/api/org/usage" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN"
```
