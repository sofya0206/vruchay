# PATCH /api/org/me

Меняет имя текущего сотрудника — то, что отвечает `GET /api/org` в `userName` и `GET /api/auth/me` в `name`. Доступно любой роли: это имя самого человека. Пробелы по краям обрезаются; пустая строка допускается.

При входе по токену API «текущий сотрудник» — это тот, кто выдал токен: запрос переименует его. Если выдавший токен сотрудник уже удалён, запрос завершится ошибкой сервера. Из интеграций этот маршрут вызывать не стоит.

## Запрос

Тело (`application/json`):

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| name | string | да | Имя, не длиннее 200 знаков после обрезки пробелов. |

```json
{
  "name": "Мария Иванова"
}
```

## Ответ

`200 OK`

| Поле | Тип | Описание |
|---|---|---|
| ok | boolean | Всегда `true`. |

```json
{ "ok": true }
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | `name` отсутствует, не строка или длиннее 200 знаков — стандартное сообщение Zod. |
| 401 | Нет действующего токена и нет cookie-сессии. `{"statusCode":401,"message":"Требуется вход в систему","error":"Unauthorized"}` |
| 413 | Тело больше 1 МБ. |

## Пример

```bash
curl -X PATCH "https://vruchay.ru/api/org/me" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Мария Иванова"}'
```
