# POST /api/documents/{id}/recipients/parse

Читает загруженный файл (Excel `.xlsx` или CSV) и возвращает, что в нём распознано: имя листа, строку с шапкой, колонки с подобранными латинскими именами переменных и сами строки. В базу ничего не записывается — это предварительный просмотр. Импорт подтверждается отдельным запросом `POST /api/documents/{id}/recipients/import`, в который клиент передаёт уже проверенные колонки и строки.

Разбор берёт не больше 10 000 строк и 30 колонок; если строк больше, в `warnings` появится предупреждение «Взяты первые 10000 строк — остальные не поместились». Файл сначала пробуется прочитать как протокол мероприятия (группы, места, двухуровневая шапка); если в нём нашлись графа места или группы, ответ содержит поле `protocol`. Если в файле фамилия, имя и отчество лежат отдельными колонками, а колонки `name` нет, разбор добавляет собранную колонку «ФИО» (`suggested: "name"`) в конец и сообщает об этом в `warnings`.

## Запрос

Тело — `multipart/form-data`, одно поле `file`. Лимит размера файла — 10 МБ (`MAX_TABLE_BYTES` = 10 485 760 байт). Принимаются расширения `.xlsx`, `.csv`, `.txt`, `.tsv`.

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `id` | UUID (путь) | да | Идентификатор документа, к которому будет привязана таблица |
| `headers` | `auto` \| `headers` \| `none` (строка запроса) | нет | Как читать первую строку данных: `auto` — решает разбор (по умолчанию); `headers` — первая строка точно шапка; `none` — шапки нет, все строки данные. Для файла, распознанного как протокол, параметр не действует |

## Ответ

`201 Created`

| Поле | Тип | Описание |
|---|---|---|
| `sheetName` | string | Имя листа книги; для CSV — имя файла без расширения |
| `headerRowIndex` | number | Номер строки с шапкой, от нуля, в координатах исходного файла |
| `columns` | array | Колонки файла, по порядку |
| `columns[].source` | string | Заголовок из файла («ФИО», «Электронная почта») |
| `columns[].suggested` | string | Подобранное латинское имя переменной (`name`, `email`, `place` и т. п. либо транслитерация заголовка) |
| `columns[].guessed` | boolean | `true`, если имя подобрано по значениям колонки, а не по заголовку, — такое стоит проверить глазами |
| `rows` | string[][] | Строки данных, значения по порядку колонок |
| `skippedEmptyRows` | number | Сколько строк отброшено как полностью пустые |
| `headerMode` | `headers` \| `none` | Как в итоге разобрана первая строка |
| `firstRowLooksLikeData` | boolean | Первая строка похожа на данные, а не на заголовки — вероятно, вставлен диапазон без шапки |
| `suggestions` | array | Предлагаемые правки текста; применяет их клиент, а не разбор |
| `suggestions[].kind` | `uppercase` \| `email-homoglyph` | ФИО прописными буквами / кириллица, похожая на латиницу, в адресе почты |
| `suggestions[].column` | number | Индекс колонки в `columns` |
| `suggestions[].columnTitle` | string | Заголовок колонки |
| `suggestions[].count` | number | Сколько ячеек изменится |
| `suggestions[].before`, `suggestions[].after` | string | Пример «было → стало» из первой затронутой ячейки |
| `suggestions[].values` | string[] | Готовые значения колонки по строкам — можно подставить в `rows` как есть |
| `warnings` | string[] | Предупреждения для человека (другой лист, обрезанные строки, собранное ФИО и т. п.) |
| `protocol` | object \| отсутствует | Есть, только если файл прочитан как протокол мероприятия |
| `protocol.groupColumn` | string | Имя колонки, по которой строки делятся на группы; пусто — групп нет |
| `protocol.groups` | array | Группы: `{ title: string, rowCount: number }` |
| `protocol.headerRowCount` | number | Сколько строк заняла шапка: 1 или 2 |

```json
{
  "sheetName": "Лист1",
  "headerRowIndex": 2,
  "columns": [
    { "source": "ФИО", "suggested": "name", "guessed": false },
    { "source": "Электронная почта", "suggested": "email", "guessed": false },
    { "source": "Место", "suggested": "place", "guessed": false }
  ],
  "rows": [
    ["Иванова Мария Сергеевна", "ivanova@example.com", "1"],
    ["Петров Олег Иванович", "petrov@example.com", "2"]
  ],
  "skippedEmptyRows": 1,
  "headerMode": "headers",
  "firstRowLooksLikeData": false,
  "suggestions": [],
  "warnings": []
}
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | `Некорректный идентификатор` — `id` не UUID |
| 400 | Значение `headers` не из списка `auto`, `headers`, `none` (сообщение Zod для enum) |
| 400 | `Файл не передан` — в multipart нет части `file` |
| 400 | `Поддерживаются файлы Excel (.xlsx) и CSV` — расширение не `.xlsx`, `.csv`, `.txt`, `.tsv` |
| 400 | `Файл слишком большой, максимум 10 МБ` |
| 400 | `Не удалось прочитать файл. Проверьте, что это таблица Excel или CSV и в ней есть строка с названиями колонок` — любая ошибка разбора (в том числе старый `.xls` или HTML с расширением `.xls`) |
| 401 | Нет токена или сессии |
| 404 | `Документ не найден` — документа нет, он удалён или принадлежит другой организации |
| 406 | Запрос отправлен не как `multipart/form-data` (ответ @fastify/multipart) |

## Пример

```bash
curl -X POST "https://vruchay.ru/api/documents/$DOCUMENT_ID/recipients/parse?headers=auto" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN" \
  -F "file=@table.xlsx"
```
