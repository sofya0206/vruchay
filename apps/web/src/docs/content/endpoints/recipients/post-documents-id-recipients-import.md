# POST /api/documents/{id}/recipients/import

Записывает таблицу получателей в документ: заводит недостающие колонки и добавляет строки. Обычно сюда передают результат `POST …/recipients/parse` после проверки сопоставления колонок, но можно прислать и данные, собранные самостоятельно (например, из CRM). Всё идёт одной транзакцией (таймаут 60 с): либо записывается всё, либо ничего.

Как обрабатываются колонки: имя из `columns[i]` сопоставляется с существующими колонками документа по `name`. Новые колонки создаются в конец с заголовком из `titles[i]` (пустой заголовок не записывается). У существующей колонки заголовок проставляется, только если его ещё не было; готовый заголовок не трогается. Колонки `name` и `email` есть у документа изначально.

Как обрабатываются строки: `rows[i][j]` — значение колонки `columns[j]`; недостающие значения в строке становятся пустой строкой. В режиме `append` (по умолчанию) строки дописываются после существующих; в режиме `replace` все прежние строки документа сначала удаляются (колонки остаются). Новые строки создаются отмеченными к выпуску.

Ограничения: до 30 колонок и до 10 000 строк за запрос (`importSchema`). Предел тела запроса у этого маршрута — `MAX_IMPORT_BODY_BYTES` = 16 МБ (16 777 216 байт), а не 1 МБ как у остальных.

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `id` | UUID (путь) | да | Идентификатор документа |

Тело:

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `columns` | string[] | да | Имена колонок, 1–30: латинские буквы, цифры, `_`, первый символ буква, до 64 символов (это `suggested` из ответа parse) |
| `titles` | string[] | нет | Заголовки тех же колонок из файла (это `source` из ответа parse), каждый до 200 символов; длина массива обязана совпадать с `columns` |
| `rows` | string[][] | да | Строки, до 10 000; в каждой до 30 значений, каждое до 1000 символов |
| `mode` | `append` \| `replace` | нет | Дописать (по умолчанию) или заменить строки целиком |

```json
{
  "columns": ["name", "email", "place"],
  "titles": ["ФИО", "Электронная почта", "Место"],
  "rows": [
    ["Иванова Мария Сергеевна", "ivanova@example.com", "1"],
    ["Петров Олег Иванович", "petrov@example.com", "2"]
  ],
  "mode": "replace"
}
```

## Ответ

`201 Created`

| Поле | Тип | Описание |
|---|---|---|
| `imported` | number | Сколько строк добавлено |
| `columns` | string[] | Имена всех колонок документа после импорта (прежние и созданные) |

```json
{ "imported": 2, "columns": ["name", "email", "place"] }
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | `Некорректный идентификатор` — `id` не UUID |
| 400 | `Введите название колонки` / `Латинские буквы, цифры и подчёркивание; первым символом — буква` — имя в `columns` не по шаблону |
| 400 | `Заголовков столько же, сколько колонок` — длина `titles` не равна длине `columns` |
| 400 | `columns` пуст или больше 30; `rows` больше 10 000; строка длиннее 30 значений; значение длиннее 1000 символов; заголовок длиннее 200; `mode` не из списка (сообщения Zod) |
| 401 | Нет токена или сессии |
| 404 | `Документ не найден` |
| 413 | Тело больше 16 МБ |

## Пример

```bash
curl -X POST "https://vruchay.ru/api/documents/$DOCUMENT_ID/recipients/import" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"columns":["name","email"],"titles":["ФИО","Почта"],"rows":[["Иванова Мария Сергеевна","ivanova@example.com"]],"mode":"append"}'
```
