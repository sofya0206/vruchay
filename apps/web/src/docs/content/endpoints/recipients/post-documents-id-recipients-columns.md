# POST /api/documents/{id}/recipients/columns

Добавляет колонку в конец таблицы получателей. Имя колонки — это имя переменной в макете (`%name`), поэтому оно должно быть латинским. Колонка создаётся без заголовка (`title: null`); заголовок появляется только при импорте файла с шапкой. Существующие строки значения в новой колонке не получают — в `data` ключ появится после правки строки.

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `id` | UUID (путь) | да | Идентификатор документа |

Тело:

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `name` | string | да | 1–64 символа после обрезки пробелов; латинские буквы, цифры и `_`, первым символом — буква |

```json
{ "name": "course" }
```

## Ответ

`201 Created` — созданная колонка.

| Поле | Тип | Описание |
|---|---|---|
| `id` | UUID | Идентификатор колонки |
| `documentId` | UUID | Документ |
| `position` | number | Порядковый номер, от нуля (равен числу колонок до добавления) |
| `name` | string | Имя переменной |
| `title` | null | Заголовка у колонки, заведённой руками, нет |

```json
{ "id": "7c0d…", "documentId": "9a2b…", "position": 2, "name": "course", "title": null }
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | `Некорректный идентификатор` — `id` не UUID |
| 400 | `Введите название колонки` — пустое имя |
| 400 | `Латинские буквы, цифры и подчёркивание; первым символом — буква` — имя не по шаблону |
| 400 | Имя длиннее 64 символов (сообщение Zod для `max`) |
| 400 | `Колонка «<name>» уже есть` — имя занято в этом документе |
| 401 | Нет токена или сессии |
| 404 | `Документ не найден` |

## Пример

```bash
curl -X POST "https://vruchay.ru/api/documents/$DOCUMENT_ID/recipients/columns" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"course"}'
```
