# PATCH /api/documents/{id}/recipients/columns/{columnId}

Переименовывает колонку и одной транзакцией переносит значения во всех строках под новый ключ (значения хранятся по имени, а не по идентификатору колонки), а также переписывает макеты листов документа: поля, ссылавшиеся на прежнее имя, начинают ссылаться на новое. Заголовок `title` не меняется.

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `id` | UUID (путь) | да | Идентификатор документа |
| `columnId` | UUID (путь) | да | Идентификатор колонки |

Тело:

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `name` | string | да | Новое имя: 1–64 символа, латинские буквы, цифры и `_`, первым символом — буква |

```json
{ "name": "full_name" }
```

## Ответ

`200 OK` — обновлённая колонка.

| Поле | Тип | Описание |
|---|---|---|
| `id` | UUID | Идентификатор колонки |
| `documentId` | UUID | Документ |
| `position` | number | Порядковый номер |
| `name` | string | Новое имя |
| `title` | string \| null | Заголовок из файла, без изменений |

```json
{ "id": "3f1c…", "documentId": "9a2b…", "position": 0, "name": "full_name", "title": "ФИО" }
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | `Некорректный идентификатор` — `id` или `columnId` не UUID |
| 400 | `Введите название колонки` / `Латинские буквы, цифры и подчёркивание; первым символом — буква` / длиннее 64 символов |
| 401 | Нет токена или сессии |
| 404 | `Документ не найден` |
| 404 | `Колонка не найдена` — колонки нет или она из другого документа |
| 500 | Новое имя занято другой колонкой документа (нарушение уникальности не перехватывается) |

## Пример

```bash
curl -X PATCH "https://vruchay.ru/api/documents/$DOCUMENT_ID/recipients/columns/$COLUMN_ID" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"full_name"}'
```
