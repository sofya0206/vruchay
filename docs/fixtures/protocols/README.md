# Синтетические протоколы соревнований

Четырнадцать файлов .xlsx, на которых держится разбор протоколов
(`apps/server/src/import/protocol.ts`). По тесту на каждый файл —
в `apps/server/src/import/protocol.test.ts`.

**Файлы синтетические, и это не временная мера.** Настоящий протокол — это
фамилии, годы рождения и спортивные общества несовершеннолетних участников,
то есть персональные данные, которым в публичном репозитории не место
ни при каком согласии. Фамилии здесь выдуманы, совпадения случайны.

Чего синтетика не воспроизводит — в [ограничения.md](ограничения.md).
Этот список стоит перечитывать перед каждым «парсер готов».

## Как пересобрать

```bash
pnpm --filter @gramota/server fixtures:protocols
```

Генератор — `apps/server/scripts/make-protocol-fixtures.ts`. Файлы коммитятся,
меняются только вместе с генератором. Править ожидания в тестах, чтобы они
позеленели, нельзя: фикстуры описывают, как выглядят настоящие протоколы,
а не то, что умеет сегодняшний код.

## Что в каком файле

| Файл | Что проверяет |
| --- | --- |
| `01-простой.xlsx` | Опорный случай: шапка в первой строке, одна группа, места подряд. Всё остальное — отклонения от него |
| `02-шапка-ниже.xlsx` | Название протокола, даты и место сверху; шапка в пятой строке. Название растянуто объединением на все колонки и читается как шесть заголовков — самая правдоподобная ловушка |
| `03-двухуровневая-шапка.xlsx` | «Участник» над «Фамилия, имя» и «Г.р.», «Результат» над «Время» и «Очки»; «№», «Команда» и «Место» объединены по вертикали на оба уровня |
| `04-группа-колонкой.xlsx` | Группа отдельной колонкой, объединённой по вертикали внутри каждой группы |
| `05-несколько-групп.xlsx` | Три группы в одном файле, в каждой места считаются с единицы |
| `06-заголовки-групп-строками.xlsx` | Группы обозначены строкой поперёк таблицы, отдельной колонки нет — парсер создаёт её сам |
| `07-статусы.xlsx` | DSQ, DNS, DNF в своей графе, и отдельно — DSQ, вписанный прямо вместо места |
| `08-делёж-дефис.xlsx` | Делёж мест через дефис: «3-4» у двоих |
| `09-делёж-равно.xlsx` | Делёж мест знаком равенства: «=1», «=3». Плюс «б/м» — место не занято |
| `10-фио-заглавными.xlsx` | ФИО заглавными, в том числе с дефисом и инициалами; одна строка в обычном регистре — её трогать нельзя |
| `11-год-рождения.xlsx` | Год числом, у одного участника вместо года полная дата, у другого — «2009 г.р.» текстом |
| `12-результат-время.xlsx` | Время числом в формате `mm:ss.00`, время текстом с запятой, дистанция длиннее часа, десятичные очки |
| `13-команда-объединённая.xlsx` | Колонка «Команда» объединена по вертикали: значение только в верхней ячейке |
| `14-тренер.xlsx` | Один тренер на нескольких спортсменов, в двух группах; часть ячеек тренера объединена. На этом файле проверяется дедупликация благодарностей |

## Что именно проверяется в каждом файле, кроме перечисленного

Во всех файлах, где есть графа места, проверяется ещё и то, что парсер
**не** тронул: место остаётся строкой ровно в том виде, как записано
(`«3-4»`, `«=3»`, `«б/м»`). Разбирать его — дело правил награждения
(`parsePlace` в `@gramota/shared`), а не импорта: испортив запись при
импорте, восстановить её будет уже не из чего.
