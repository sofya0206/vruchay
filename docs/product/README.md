# Управление продуктом «Вручай»

Текущий порядок работы:

1. UX и путь пользователя.
2. Тарифная логика.
3. Название и позиционирование.
4. UI.
5. Разработка основной механики.
6. API и интеграции.

Основной путь пользователя:

`Аккаунт → макет → Excel/CSV → проверка → выпуск → письмо / архив / виджет`

Документы этого раздела фиксируют принятые решения. Для каждого изменения создаётся временная Git-ветка; после проверки она объединяется с `main`.
