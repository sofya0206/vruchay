# ADR-0002. Облачный провайдер и состав инфраструктуры

Статус: **предложено** (часть по Беларуси — ждёт юридического заключения) · Дата: 31.07.2026

## Контекст

Нужен хостинг для сервиса: приложение на Node.js с headless Chromium (генерация PDF),
PostgreSQL, Redis, S3-хранилище. Нагрузка на первый год — до 1000 документов в месяц.
Данные должны обрабатываться в РФ (ч.5 ст.18 152-ФЗ). Владелец — не DevOps, важна
простота панели и живая поддержка. Бюджет 10–15 тыс ₽/мес.

Рассматривались Timeweb Cloud и Selectel (оба — российские, ЦОДы в РФ).

## Решение: Timeweb Cloud, локация Москва или Санкт-Петербург

### Почему не Selectel

Selectel дешевле по «голому железу» (VDS 4/8/80 — 1 100 ₽ против 1 980 ₽) и сильнее по
формальным бумагам (аттестат ФСТЭК №1811, УЗ-1…УЗ-4, ISO 27001, PCI DSS). Но:

- **У Selectel нет managed-конфигураций нашего размера.** Минимальный кластер PostgreSQL —
  от ~3 700 ₽/мес против 790–1 580 ₽ у Timeweb; managed Redis — ~3 500 ₽ против 670 ₽
  (и у Selectel это Redis 6, у Timeweb — Valkey). Экономия на серверах полностью съедается.
- **Модель работы рассчитана на инженерные команды**: поддержка только через тикеты,
  панель с логикой OpenStack (проекты, подсети, роутеры). У Timeweb — чат и Telegram
  с ответом за минуты, приватный IP у БД по умолчанию, маркетплейс приложений.
- **Порог входа в Kubernetes** на будущее: у Timeweb тестовый кластер за 1 ₽, у Selectel
  одна мастер-нода ~5 955 ₽/мес — дороже, чем весь наш текущий стек.
- Аттестат ФСТЭК Selectel нам сейчас не нужен: ФИО + email + организация без спецкатегорий
  — это УЗ-3/УЗ-4, для него достаточно РФ-локации и договора-поручения (есть у обоих).

### Ревизия плана: PostgreSQL и Redis — в Docker на prod-VPS, а не managed

План изначально предполагал managed PostgreSQL. Пересматриваем: при 1000 документов в месяц
(≈1–2 генерации в час в пике) managed-кластер за 1 580 ₽ будет простаивать, а экономия
составляет ~19–27 тыс ₽/год. Оценка памяти на 8 ГБ: Node 0,3–0,5 ГБ + Chromium 0,4–0,8 ГБ
(пики до 1,5) + PostgreSQL ~1,2–1,5 ГБ + Redis 0,1–0,3 ГБ + ОС 0,5–0,7 ГБ = 2,5–4,5 ГБ,
запас достаточный. Переезд на managed позже — это `pg_dump`/`pg_restore` и смена DSN, час работы.

**Условия, без которых так делать нельзя** (выполнить в Фазе 0–1, не «потом»):

- ежедневный `pg_dump` → S3 с ретеншеном 30 дней;
- **ежемесячная проверка восстановления** дампа на staging (непроверенный бэкап = его нет);
- жёсткие `mem_limit` на контейнер воркера с Chromium, чтобы OOM-killer не убил PostgreSQL;
- данные PostgreSQL — на именованном volume, порт 5432 наружу не публикуется;
- конкурентность очереди генерации 1–2.

**Переезжаем на managed PostgreSQL**, когда: нагрузка &gt; ~100 документов/день, БД &gt; нескольких ГБ,
появился второй человек в проекте, сорвалось восстановление из бэкапа, пришёл клиент с SLA,
или начались OOM от соседства Chromium и БД.

### Стартовая конфигурация

| Позиция | Конфигурация | ₽/мес |
|---|---|---|
| Prod VPS | Cloud MSK 80 — 4 vCPU / 8 ГБ / 80 ГБ NVMe (приложение + Chromium + PostgreSQL + Redis) | 1 980 |
| Staging VPS | Cloud MSK 50 — 2 vCPU / 4 ГБ / 50 ГБ (почасовая оплата, гасим на ночь) | 1 180 |
| S3 | 20 ГБ: файлы, дампы БД, WAL | 349 |
| **Итого** | | **≈ 3 509** (≈ 3 158 при годовой предоплате) |

Остаток бюджета — резерв на managed PostgreSQL (+1 580), апгрейд prod (+1 100), домен, мониторинг.

## Риски и что с ними делаем

- **Локации.** У Timeweb есть Франкфурт, Амстердам, Алматы — **брать нельзя**, это прямое
  нарушение локализации ПДн. Только Москва / Санкт-Петербург / Новосибирск.
- **Качество процессов провайдера.** В мае–июне 2026 зона Timeweb ams-1 (Амстердам, арендованный
  ЦОД) дала ~46 часов простоя за два месяца при SLA 99,98%, обещанные постмортемы не вышли.
  Российские площадки в этой истории не фигурируют, но вывод: на SLA не полагаемся, свои
  бэкапы в S3 обязательны.
- **Рост цен.** Timeweb поднимал цены в 2026 — закладываем 10–15% в год.

## Что сделать в первую неделю

1. Запросить у Timeweb через тикет **договор-поручение на обработку персональных данных**.
2. Подать **уведомление оператора ПДн в Роскомнадзор** (наша зона ответственности, не провайдера).
3. Настроить `pg_dump` → S3 по cron и **проверить восстановление**.
4. Если есть ИП — зарегистрироваться в Selectel и взять **грант до 30 000 ₽** на месяц:
   бесплатно протестировать их DBaaS и иметь обоснованный план Б.
