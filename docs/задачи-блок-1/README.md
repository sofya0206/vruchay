# Блок 1. Главный экран — задания для параллельных сессий

Четыре задания, каждое в своей ветке и своём ворктри. Пятая и шестая подзадачи блока (1.4 Интеграции и 1.5 Оплата) сейчас не запускаются: первая слишком велика и в ней висит неслитая ветка `tilda-integration`, вторая требует решений по юрлицу, ЮКассе и Точке.

| Файл | Подзадача | Что делает |
|---|---|---|
| `1-1-оболочка-и-обзор.md` | 1.1 | Оболочка кабинета, навигация, маршруты, вкладка «Обзор» |
| `1-2-документы.md` | 1.2 | Библиотека шаблонов, готовые заготовки, копия под мероприятие |
| `1-3-рассылка.md` | 1.3 | Отдельный раздел рассылки, журнал доставки, два потока писем |
| `1-6-реестр-и-аналитика.md` | 1.6 + 1.7 | Архив выданного, перевыпуск, аналитика на существующих данных |

Оболочку, навигацию и `App.tsx` правит только 1.1. Остальные добавляют одну строку маршрута и живут в своих папках.

Порядок слияния: сначала 1.1 (в неё втыкаются остальные), затем 1.2, 1.3, 1.6.
