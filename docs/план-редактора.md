# План доработки редактора и кабинета

Составлен по замечаниям после первого живого прохода по сервису.
Ориентир по наполнению — редактор gramotadel.express, но с оговоркой,
которая важнее списка возможностей:

> **Делать максимально понятно для обычного человека. Тяжёлые связки
> не всегда хорошо.**

Это значит: не копировать интерфейс Word целиком, а брать из него то,
что человек уже знает, и убирать всё, чем он не воспользуется.

---

## Что есть сейчас

| Возможность | Состояние |
|---|---|
| Размер листа | поля `page_width_mm` / `page_height_mm` в базе есть, в интерфейсе не задаются — всегда 297×210 |
| Элементы листа | текст, картинка, QR, ссылка |
| Свойства текста | шрифт, кегль, цвет, выравнивание, межстрочный и межбуквенный интервал, полужирный, курсив, автоподбор |
| Шаблон письма | API готов целиком (тема, тело, вложение), интерфейса нет |
| Список документов | плоский, без превью, без папок, без меню действий |

---

## Порядок работ

Отсортировано по отношению «польза к трудозатратам», а не по порядку
в списке замечаний.

### 1. Превью документа в списке ⟵ начинаем отсюда

Сейчас список — это строки с названиями, по которым невозможно понять,
где какая грамота. Это самое заметное неудобство.

**Как:** компонент отрисовки листа (`SheetRenderer`) уже существует
и используется редактором, предпросмотром и печатью. Тот же компонент
показываем в списке уменьшенным. Картинки генерировать не нужно —
ни Playwright, ни хранилища миниатюр: браузер отрисует сам.

### 2. Размер листа

Пресеты A4, A5, A3 в двух ориентациях плюс «свой размер» в миллиметрах.
Поля в базе уже есть — нужен только выбор в интерфейсе и в создании
документа.

### 3. Меню действий у документа («три точки»)

Переименовать, дублировать, удалить, скачать пример. Привычная связка,
которую человек знает по проводнику и по любому облачному диску.

### 4. Редактор письма участнику

Тема и текст письма с переменными. **API полностью готов** — нужен
только интерфейс. Даёт много: сейчас участник получает безличное
«Ваш документ во вложении».

### 5. Предпросмотр перед выпуском

Показать, как будет выглядеть документ конкретного получателя,
до того как выпущены все. Ошибка в макете, найденная после рассылки
пятисот грамот, стоит дорого.

### 6. Панель вставки вместо кнопки «Текст»

Кнопка «Вставить» с меню: текст, изображение, QR-код, ссылка, фигура.
Понятнее, чем отдельные кнопки на каждый тип.

### 7. Богаче свойства текста

Подчёркивание, зачёркивание, ВЕРХНИЙ РЕГИСТР, тень, обводка, заливка
блока. Плюс выравнивание относительно листа и по другим блокам.

### 8. Папки и перетаскивание

Самое дорогое: нужна миграция схемы, дерево, перетаскивание. Делать
последним — до сотни документов список ищется поиском.

## Про позиционирование на посадочной

Замечание: «мы не создаём сертификаты, а подписываем их».

Прочитано так: ценность сервиса не в рисовании макета с нуля — макет
у заказчика обычно уже есть, — а в том, что мы **надписываем готовый
макет именами и рассылаем**. Тексты на посадочной надо развернуть
в эту сторону: «загрузите свой бланк — мы подпишем его каждому
участнику и разошлём».

Перед правкой текстов уточнить, верно ли прочитано.
