# POST /api/documents/{id}/validation/fix

Записывает новые значения в отдельные ячейки — по одной или сразу во многих строках (например, «ФИО прописными» во всех трёхстах строках протокола). Все правки идут одной транзакцией. Идентификаторы строк из другого документа или несуществующие молча пропускаются; по `updated` видно, сколько строк реально изменено. Несколько правок одной строки объединяются, повторная правка одной ячейки перекрывает предыдущую. Существование колонки не проверяется.

Действие записывается в журнал аудита организации (`validation.fix`): число строк и имена колонок, без значений.

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `id` | UUID (путь) | да | Идентификатор документа |

Тело:

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `fixes` | array | да | 1–5000 правок |
| `fixes[].rowId` | UUID | да | Строка |
| `fixes[].column` | string | да | Имя колонки: латинские буквы, цифры, `_`, первый символ буква |
| `fixes[].value` | string | да | Новое значение, до 1000 символов |

```json
{
  "fixes": [
    { "rowId": "b1c2…", "column": "name", "value": "Иванова Мария Сергеевна" },
    { "rowId": "c3d4…", "column": "email", "value": "petrov@example.com" }
  ]
}
```

## Ответ

`201 Created`

| Поле | Тип | Описание |
|---|---|---|
| `updated` | number | Сколько строк изменено |

```json
{ "updated": 2 }
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | `Некорректный идентификатор` — `id` не UUID |
| 400 | `Недопустимое имя колонки` — `column` не по шаблону |
| 400 | `fixes` пуст или больше 5000; `rowId` не UUID; `value` длиннее 1000 символов (сообщения Zod) |
| 401 | Нет токена или сессии |
| 404 | `Документ не найден` |
| 429 | `Слишком много попыток. Повторите через N с.` — больше 80 запросов за 5 минут с одного IP |

## Пример

```bash
curl -X POST "https://vruchay.ru/api/documents/$DOCUMENT_ID/validation/fix" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"fixes":[{"rowId":"'$ROW_ID'","column":"name","value":"Иванова Мария Сергеевна"}]}'
```
