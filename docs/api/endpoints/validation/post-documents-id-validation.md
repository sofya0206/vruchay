# POST /api/documents/{id}/validation

Проверяет строки таблицы получателей против макетов документа и возвращает отчёт: сколько строк чистых, сколько выпускать нельзя, поимённый список строк с проблемами и остаток квоты. Ничего не меняет — POST выбран вместо GET, чтобы фамилии и адреса не попадали в кэши и журналы прокси. Строки клиент не присылает: проверяются те, что уже лежат в базе.

За один запрос разбирается не больше 5000 строк (`MAX_VALIDATED_ROWS`). Если в выбранной области строк больше, отчёт содержит оговорку в `caveats` о непроверенном хвосте, а `quota.adding` при этом считается по всем строкам области — именно столько уйдёт в выпуск. Коды проблем и их серьёзность описаны в [справочнике кодов проверки](../../reference/validation-problem-codes.md). Правила награждения (места, группы) проверка не разбирает и говорит об этом в `caveats`.

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `id` | UUID (путь) | да | Идентификатор документа |

Тело:

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `scope` | `checked` \| `all` | нет | Какие строки смотреть: только отмеченные к выпуску (по умолчанию) или всю таблицу |

```json
{ "scope": "checked" }
```

## Ответ

`201 Created`

| Поле | Тип | Описание |
|---|---|---|
| `total` | number | Сколько строк проверено (не больше 5000) |
| `clean` | number | Строк без единой проблемы |
| `blocked` | number | Строк с блокирующей проблемой (`overflow`, `required_empty`, `email_invalid`) — их выпускать нельзя |
| `rows` | array | Только строки с проблемами; чистые в ответ не входят |
| `rows[].rowId` | UUID | Строка таблицы |
| `rows[].position` | number | Номер строки в таблице, с единицы |
| `rows[].title` | string | ФИО из колонки `name` или «Строка N» |
| `rows[].problems[].code` | string | Код проблемы, см. справочник |
| `rows[].problems[].column` | string \| null | Колонка, к которой относится проблема, если она одна |
| `rows[].problems[].detail` | string | Что именно не так, с подставленными числами и значениями |
| `rows[].problems[].suggestion` | string (необязательно) | Чем заменить значение — подходит для `POST …/validation/fix` |
| `quota.plan` | `free` \| `paid` | Тариф организации |
| `quota.used` | number | Уже выпущено документов |
| `quota.limit` | number \| null | Предел бесплатной пробы; `null` на оплаченном тарифе |
| `quota.left` | number \| null | Остаток |
| `quota.adding` | number | Сколько строк в выбранной области уйдёт в выпуск (без предела в 5000) |
| `caveats` | string[] | Чего проверка не знает: непроверенный хвост, нечитаемые листы, правила награждения, автомасштаб и т. п. |

```json
{

  "blocked": 1,
  "rows": [
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | `Некорректный идентификатор` — `id` не UUID |
| 400 | `scope` не из списка `checked`, `all` (сообщение Zod для enum) |
| 401 | Нет токена или сессии |
| 404 | `Документ не найден` — документа нет, он удалён или принадлежит другой организации |
| 429 | `Слишком много попыток. Повторите через N с.` — больше 40 запросов за 5 минут с одного IP |

## Пример

```bash
curl -X POST "https://vruchay.ru/api/documents/$DOCUMENT_ID/validation" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"scope":"checked"}'
```
