# GET /api/v1/public/org/{slug}

Публичная страница эмитента: кто это, чем подтверждена его личность и что он
выдаёт. Открыта без входа, заголовок `Authorization` не нужен.

Организация показывается только по своему решению (`publicPageEnabled`) и только
по адресу, который сама выбрала (`slug`). По идентификатору организации из базы
страницы нет — чтобы перебор UUID не давал списка клиентов сервиса. Если страница
выключена или адрес не задан, ответ — 404, такой же, как для несуществующей
организации.

Ничего о получателях здесь нет: ни имён, ни кодов. Программы — это материалы,
по которым что-то уже выдано и включена проверка; считаются они по выданным
файлам, а не по материалам, поэтому пустой материал на странице не появится.

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `slug` | string, `^[a-z0-9-]{1,50}$` | да | Публичный адрес организации. Регистр не важен: приводится к строчным. |

Параметров строки запроса нет.

## Ответ

`200 OK`

| Поле | Тип | Описание |
|---|---|---|
| name | string | Название организации. |
| slug | string \| null | Публичный адрес: `/org/<slug>`. |
| description | string | Описание. Пустая строка — не заполнено. |
| inn | string | ИНН. Пустая строка — не указан. |
| website | string | Сайт. Пустая строка — не указан. |
| contactEmail | string | Почта для связи. Пустая строка — не указана. |
| contactPhone | string | Телефон для связи. Пустая строка — не указан. |
| logoUrl | string \| null | Временная ссылка на логотип, действует 15 минут. `null` — логотипа нет. |
| verified | boolean | Значок «Верифицированный эмитент». |
| verifiedAt | string (ISO 8601) \| null | Когда значок выдан. |
| indexable | boolean | Пускать ли поисковики на страницу. |
| searchByName | boolean | Включён ли поиск документов по ФИО. При `false` запрос к `/search?name=…` отвечает 404. |
| programs | array | Материалы, по которым что-то выдано. Не больше 200, новые первыми. |

Элемент `programs`:

| Поле | Тип | Описание |
|---|---|---|
| id | string (UUID) | Идентификатор материала. |
| title | string | Название. |
| eventName | string | Мероприятие. Пустая строка — не указано. |
| eventDate | string | Дата мероприятия строкой, как её ввела организация. |
| issued | number | Сколько документов выдано по этому материалу. |
| firstIssuedAt | string (ISO 8601) \| null | Первый выпуск. |
| lastIssuedAt | string (ISO 8601) \| null | Последний выпуск. |

Постраничности у `programs` нет: отдаётся не больше 200 материалов, остальные
в ответ не попадают.

## Ошибки

| Код | Когда |
|---|---|
| 400 | `slug` не подходит под `^[a-z0-9-]{1,50}$` — «Некорректный адрес». |
| 404 | Организации с таким адресом нет или её публичная страница выключена: `{"statusCode":404,"message":"Организация не найдена","error":"Not Found"}`. |
| 429 | Больше 60 запросов в минуту с одного IP. |

## Пример

```bash
curl "https://vruchay.ru/api/v1/public/org/fgso"
```
