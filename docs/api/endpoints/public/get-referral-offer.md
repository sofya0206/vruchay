# GET /api/referral-offer

Что получит тот, кто регистрируется по коду приглашения. Вызывается до
регистрации — со страницы `/register?ref=<код>`, — поэтому открыт без входа
и заголовок `Authorization` не нужен.

Наружу уходит только название пригласившей организации: его она и так сообщила
тому, кому дала ссылку. Ни адреса, ни идентификатора организации в ответе нет.
Частота ограничена, иначе адрес превратился бы в способ вычитывать список
клиентов сервиса по одному коду за раз.

Неизвестный код — не ошибка: ответ `200` с `valid: false`. Показать при этом
нужно обычный бесплатный лимит, он приходит в том же ответе.

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `ref` | string ≤ 16 | да | Код приглашения из ссылки. Регистр не важен. Свой код организация берёт из `GET /api/referral`. |

Код считается годным, если после приведения к строчным подходит под
`^[a-z0-9]{4,16}$` и такая организация нашлась. Всё остальное — включая пустую
строку — даёт `valid: false`.

## Ответ

`200 OK`. Код известен:

| Поле | Тип | Описание |
|---|---|---|
| valid | boolean | `true`. |
| invitedBy | string | Название пригласившей организации. Пустая строка, если организация успела удалиться. |
| freeLimit | number | Обычный бесплатный лимит документов (настройка `FREE_DOCUMENT_LIMIT`, по умолчанию 50). |
| welcomeBonus | number | Надбавка за приход по приглашению (`REFERRAL_WELCOME_BONUS`, по умолчанию 50). |
| total | number | `freeLimit + welcomeBonus` — сколько документов будет у новичка. |

```json
{
  "valid": true,
  "invitedBy": "Учебный центр «Развитие»",
  "freeLimit": 50,
  "welcomeBonus": 50,
  "total": 100
}
```

Код неизвестен или не похож на код — ответ короче, полей о бонусе в нём нет:

| Поле | Тип | Описание |
|---|---|---|
| valid | boolean | `false`. |
| freeLimit | number | Обычный бесплатный лимит документов. |

```json
{
  "valid": false,
  "freeLimit": 50
}
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | `ref` не передан или длиннее 16 знаков — стандартное сообщение Zod. |
| 429 | Больше 20 запросов за 5 минут с одного IP. |

## Пример

```bash
curl "https://vruchay.ru/api/referral-offer?ref=k7m2qp"
```
