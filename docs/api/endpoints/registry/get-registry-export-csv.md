# GET /api/registry/export.csv

Тот же реестр таблицей для Excel — по тому же отбору, что и
`GET /api/registry`. Отдаётся не больше 20 000 строк, новые первыми;
если документов в отборе больше, остальные в файл не попадают — сузьте отбор
периодом или материалом. Ответ — файл, а не JSON.

## Запрос

Параметры строки запроса — общий отбор реестра
([reference/registry-filter.md](../../reference/registry-filter.md)).

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `search` | string ≤ 200 | нет | Имя, почта или проверочный код целиком. |
| `documentId` | UUID | нет | Материал. |
| `event` | string ≤ 200 | нет | Мероприятие, точное совпадение. |
| `state` | `valid` \| `revoked` \| `replaced` \| `expired` | нет | Состояние документа. |
| `mail` | `none` \| `queued` \| `sent` \| `delivered` \| `opened` \| `bounced` \| `failed` | нет | Состояние письма. |
| `from` | дата | нет | Выпущен не раньше этого дня (по Москве). |
| `to` | дата | нет | Выпущен не позже этого дня включительно. |

## Ответ

`200 OK`, файл.

| Заголовок | Значение |
|---|---|
| `Content-Type` | `text/csv; charset=utf-8` |
| `Content-Disposition` | `attachment; filename="..."; filename*=UTF-8''%D0%A0%D0%B5%D0%B5%D1%81%D1%82%D1%80%20%D0%B2%D1%8B%D0%B4%D0%B0%D0%BD%D0%BD%D0%BE%D0%B3%D0%BE.csv` (имя «Реестр выданного.csv») |

Формат: метка порядка байтов (BOM) в начале, разделитель `;`, строки через
`\r\n`, каждая ячейка в двойных кавычках (кавычки внутри удвоены). Значения,
начинающиеся с `=`, `+`, `-`, `@`, табуляции или перевода строки, получают
апостроф спереди — чтобы Excel не выполнил их как формулу. Даты — `ДД.ММ.ГГГГ`
по Москве.

Колонки по порядку:

| Колонка | Откуда |
|---|---|
| № | Порядковый номер в выгрузке. |
| ФИО | `name` строки реестра. |
| Адрес почты | `email`. |
| Материал | `documentTitle`. |
| Мероприятие | `eventName`. |
| Выдан | `issuedAt`. |
| Действителен до | `expiresAt`, пусто у бессрочных. |
| Проверочный код | `code`. |
| Состояние | `действителен`, `перевыпускается`, `отозван`, `заменён`, `срок истёк`. |
| Письмо | `не отправлялось`, `в очереди`, `отправлено`, `доставлено`, `прочитано`, `не доставлено`, `ошибка`. |
| Проверок по QR | `verifyCount`. |
| Удаление по сроку | Дата `retention.purgeAt`, пусто, если материал не в корзине. |

```
"№";"ФИО";"Адрес почты";"Материал";"Мероприятие";"Выдан";"Действителен до";"Проверочный код";"Состояние";"Письмо";"Проверок по QR";"Удаление по сроку"
"1";"Иванова Мария Петровна";"ivanova@example.com";"Сертификат участника";"Открытый кубок города";"15.06.2026";"";"K7M2-9QXR-4TVB";"действителен";"доставлено";"3";""
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | Те же ошибки отбора, что у `GET /api/registry`: «Некорректный идентификатор материала», «Неизвестное состояние документа», «Неизвестное состояние письма», «Не удалось разобрать дату начала периода», «Не удалось разобрать дату конца периода». |
| 401 | Нет токена или сессии. |

## Пример

```bash
curl "https://vruchay.ru/api/registry/export.csv?documentId=$DOCUMENT_ID" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN" \
  -o registry.csv
```
