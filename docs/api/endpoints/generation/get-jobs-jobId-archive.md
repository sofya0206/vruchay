# GET /api/jobs/{jobId}/archive

Отдаёт готовый пакет файлом: ZIP со всеми документами задания или один PDF
на всю пачку для печати. Ссылки на хранилище здесь нет — байты идут прямо
в ответе, скачивать надо с тем же заголовком `Authorization`.

Скачивание ничего не выпускает и квоту не трогает: списывается она в момент
создания файла. Архив можно забирать сколько угодно раз и в любом состоянии
задания — в нём будут документы, созданные к этому моменту.

ZIP собирается потоком: заголовки уходят до того, как прочитан первый файл,
`content-length` в ответе нет. Обратная сторона в том, что беда посреди отдачи
обрывает уже начатый ответ, а не превращается в код ошибки, — недокачанный
архив выглядит как разрыв связи. Общий PDF, наоборот, собирается в памяти
целиком, и поэтому у него есть пределы: перед `?format=pdf` спросите
[`GET /api/jobs/{jobId}/download-options`](get-jobs-jobId-download-options.md).

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `jobId` | UUID (путь) | да | Идентификатор задания |
| `format` | `zip` \| `pdf` | нет | `zip` (по умолчанию) — архив всех файлов задания; `pdf` — один документ со всеми страницами подряд |
| `name` | string | нет | Шаблон имени файлов внутри архива, 1–120 символов. Для `format=pdf` не нужен и не используется |

Шаблон `name`: `%имя_колонки` подставляет значение колонки таблицы получателей
на момент выпуска, `%number` — порядковый номер в архиве с единицы,
`%publicId` — проверочный идентификатор документа. Неизвестная переменная
становится пустотой. Символы `\ / : * ? " < > |` в шаблоне запрещены;
результат очищается ещё раз, обрезается до 80 символов и получает расширение
`.pdf` или `.jpg` по типу файла. Тёзки не перезаписывают друг друга — второму
дописывается ` (2)`.

Без `name` имя берётся то, под которым файл выпущен (это шаблон `%name` с
номером строки в таблице). Это не то же самое, что передать `name=%name`:
у файлов, выпущенных до появления шаблонов, строки-источника может уже не быть,
и собирать имя было бы не из чего.

## Ответ

`200 OK`, файл.

При `format=zip` (по умолчанию):

- `Content-Type: application/zip`
- `Content-Disposition: attachment; filename="___________.zip"; filename*=UTF-8''%D0%A1%D0%B5%D1%80%D1%82%D0%B8%D1%84%D0%B8%D0%BA%D0%B0%D1%82%D1%8B.zip`
  (имя файла — «Сертификаты.zip»; в кавычках стоит его ASCII-заглушка, настоящее
  имя — в `filename*`)
- `Content-Length` отсутствует, тело идёт потоком

В архив попадают все файлы задания — и PDF, и JPEG, — без вложенных каталогов.

При `format=pdf`:

- `Content-Type: application/pdf`
- `Content-Disposition` с именем «Сертификаты на печать.pdf»

Склеиваются только PDF-файлы задания, в том же порядке, в каком они выпущены.
JPEG в общий файл не попадают. Отдельные нечитаемые исходники молча
пропускаются (запись об этом остаётся в журнале сервера).

## Ошибки

| Код | Когда |
|---|---|
| 400 | `Некорректный идентификатор` — `jobId` не UUID |
| 400 | `Шаблон имени не может быть пустым` / `Шаблон имени длиннее 120 символов` / `В шаблоне имени нельзя использовать символы \ / : * ? " < > \|` |
| 400 | Неизвестное значение `format` — сообщение Zod |
| 400 | `В этом выпуске нет ни одного PDF — общий файл собрать не из чего.` — при `format=pdf` |
| 400 | `Документов слишком много для одного файла: N при пределе 300. Скачайте архивом — в нём тот же комплект.` |
| 400 | `Пачка слишком тяжёлая для одного файла: N МБ при пределе 150 МБ. Скачайте архивом — в нём тот же комплект.` |
| 400 | `Не удалось собрать общий файл: документы этого задания не читаются как PDF` |
| 401 | Нет токена или сессии |
| 404 | `Задание не найдено` — нет такого или оно чужой организации |

Пустое задание (ни одного файла) при `format=zip` отдаётся как пустой архив,
а не ошибкой.

## Пример

```bash
curl "https://vruchay.ru/api/jobs/$JOB_ID/archive?format=zip&name=%25number%20%25name" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN" \
  -o archive.zip
```

Здесь `%25` — это знак `%` в адресе, то есть шаблон `%number %name`: файлы
приедут как «1 Иванова Мария Петровна.pdf».

Один файл на печать:

```bash
curl "https://vruchay.ru/api/jobs/$JOB_ID/archive?format=pdf" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN" \
  -o print.pdf
```
