# GET /api/jobs/{jobId}/download-options

Что сейчас можно сделать с готовым пакетом: сколько в нём файлов, сколько они
весят и поместится ли пачка в один PDF на печать. Спрашивать это нужно до
скачивания, а не после: общий PDF собирается в памяти, и большому пакету в ней
не поместиться — узнать об этом отказом посреди начатого скачивания значит
получить голый JSON вместо файла.

Считаются только файлы этого задания, у которых есть байты в хранилище и
которые не в корзине. Задание может быть ещё не закончено — тогда здесь видно,
сколько документов создано к этому моменту.

Пределы на общий PDF — `PRINT_MERGE_LIMIT_FILES` (по умолчанию 300 документов)
и `PRINT_MERGE_LIMIT_MB` (по умолчанию 150 МБ). Ровно эта же проверка стоит
на самом скачивании, поэтому `print.allowed: false` здесь означает 400 там.

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `jobId` | UUID (путь) | да | Идентификатор задания |

Тела нет.

## Ответ

`200 OK`

| Поле | Тип | Описание |
|---|---|---|
| `count` | number | Сколько всего файлов в задании — и PDF, и JPEG. Столько записей будет в архиве |
| `pdfCount` | number | Сколько из них PDF. Только они попадают в общий файл на печать |
| `sizeBytes` | number | Суммарный размер PDF-файлов в байтах. JPEG в сумму не входит |
| `print` | object | Вердикт по общему PDF, см. ниже |

`print`:

| Поле | Тип | Описание |
|---|---|---|
| `allowed` | boolean | Можно ли запросить `?format=pdf` |
| `reason` | string \| null | Почему нельзя. Null, когда можно |
| `limitFiles` | number | Действующий предел по числу документов |
| `limitMb` | number | Действующий предел по объёму, МБ |

```json
{
  "count": 127,
  "pdfCount": 127,
  "sizeBytes": 41517284,
  "print": { "allowed": true, "reason": null, "limitFiles": 300, "limitMb": 150 }
}
```

Отказ выглядит так:

```json
{
  "count": 412,
  "pdfCount": 412,
  "sizeBytes": 168000000,
  "print": {
    "allowed": false,
    "reason": "Документов слишком много для одного файла: 412 при пределе 300. Скачайте архивом — в нём тот же комплект.",
    "limitFiles": 300,
    "limitMb": 150
  }
}
```

Три возможных текста `reason`:

- `В этом выпуске нет ни одного PDF — общий файл собрать не из чего.` —
  `pdfCount` равен нулю (в том числе когда выпуск шёл в JPEG);
- `Документов слишком много для одного файла: N при пределе 300. Скачайте
  архивом — в нём тот же комплект.`;
- `Пачка слишком тяжёлая для одного файла: N МБ при пределе 150 МБ. Скачайте
  архивом — в нём тот же комплект.`

## Ошибки

| Код | Когда |
|---|---|
| 400 | `Некорректный идентификатор` — `jobId` не UUID |
| 401 | Нет токена или сессии |
| 404 | `Задание не найдено` — нет такого или оно чужой организации |

## Пример

```bash
curl "https://vruchay.ru/api/jobs/$JOB_ID/download-options" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN"
```
