# GET /api/documents/{id}/jobs

Последние выпуски по материалу — новые первыми. Отсюда берут `jobId`, если он
не сохранён: например, чтобы скачать архив вчерашнего выпуска или продолжить
упавший. Здесь же видно, идёт ли по материалу выпуск прямо сейчас — если
у первой записи `status` равен `queued` или `running`, новый запустить нельзя.

Выдача урезана до десяти записей. Постраничности нет: ни `limit`, ни `offset`
маршрут не принимает, и запросить одиннадцатый выпуск через API нельзя.

Материал не проверяется отдельным запросом: отбор идёт по паре
«организация + материал», поэтому для несуществующего или чужого материала
вернётся пустой массив, а не 404.

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `id` | UUID (путь) | да | Идентификатор материала |

Тела нет.

## Ответ

`200 OK` — массив записей задания (см.
[reference/generation-job.md](../../reference/generation-job.md)), от новых
к старым по `createdAt`, не больше 10. Поля `stuck` здесь нет — оно есть только
в `GET /api/jobs/{jobId}`.

```json
[
  {
    "id": "5c8f1a2b-3d4e-4f50-8a6b-7c8d9e0f1a2b",
    "orgId": "1a2b3c4d-5e6f-4708-9a0b-1c2d3e4f5a6b",
    "documentId": "b1c2d3e4-f5a6-4b7c-8d9e-0f1a2b3c4d5e",
    "format": "pdf",
    "status": "done",
    "total": 128,
    "done": 127,
    "failed": 1,
    "error": "Не удалось создать файлов: 1",
    "chunks": 3,
    "attempt": 1,
    "createdAt": "2026-06-15T09:12:44.000Z",
    "startedAt": "2026-06-15T09:12:51.000Z",
    "finishedAt": "2026-06-15T09:15:38.000Z"
  }
]
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | `Некорректный идентификатор` — `id` не UUID |
| 401 | Нет токена или сессии |

## Пример

```bash
curl "https://vruchay.ru/api/documents/$DOCUMENT_ID/jobs" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN"
```
