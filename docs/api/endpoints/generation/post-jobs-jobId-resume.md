# POST /api/jobs/{jobId}/resume

Доделывает то же самое задание с того места, где оно встало. Принимается для
упавшего (`failed`), отменённого (`canceled`) и зависшего задания — то есть
такого, у которого `stuck: true` в `GET /api/jobs/{jobId}`. Идущий выпуск
(`queued` без признака зависания или `running`) и завершённый (`done`)
продолжать нечего.

Это не то же самое, что новый выпуск. Новый выпуск — новое задание и новая
оплата: список могли исправить и захотеть второй комплект. Продолжение идёт под
тем же `jobId`, за уже созданные документы второй раз не списывается, а квота
проверяется только для оставшихся строк.

Строки берутся отмеченные сейчас, а не те, что были отмечены при запуске: если
отметки за это время сняли, документы по ним не выпускаются. Поэтому `total`
пересчитывается, `failed` обнуляется, прежние причины неудач стираются,
а `attempt` увеличивается на единицу. Если доделывать оказалось нечего (все
отмеченные строки уже выпущены), задание просто закрывается: приходит запись
со `status: "done"`, у которой `total` и `done` равны числу уже выпущенных
файлов, и в очередь ничего не ставится.

Как и запуск, продолжение асинхронное: ответ означает «принято», а не «готово».

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `jobId` | UUID (путь) | да | Идентификатор задания |

Тела нет.

## Ответ

`201 Created` — обновлённая запись задания, см.
[reference/generation-job.md](../../reference/generation-job.md).

```json
{
  "id": "5c8f1a2b-3d4e-4f50-8a6b-7c8d9e0f1a2b",
  "orgId": "1a2b3c4d-5e6f-4708-9a0b-1c2d3e4f5a6b",
  "documentId": "b1c2d3e4-f5a6-4b7c-8d9e-0f1a2b3c4d5e",
  "format": "pdf",
  "status": "queued",
  "total": 128,
  "done": 74,
  "failed": 0,
  "error": null,
  "chunks": 3,
  "attempt": 2,
  "createdAt": "2026-06-15T09:12:44.000Z",
  "startedAt": "2026-06-15T09:12:51.000Z",
  "finishedAt": null
}
```

`chunks` здесь ещё от прошлой попытки: новое число частей записывается уже после
того, как запись обновлена.

## Ошибки

| Код | Когда |
|---|---|
| 400 | `Некорректный идентификатор` — `jobId` не UUID |
| 400 | `Этот выпуск уже завершён — продолжать нечего` — `status` = `done` |
| 400 | `Этот выпуск и так идёт` — `status` = `running` либо `queued` без признака `stuck` |
| 400 | `Этот выпуск уже продолжили` — задание перестало быть продолжаемым, пока запрос ждал замка организации (два продолжения разом) |
| 400 | `Одновременно можно выпускать не больше N пакетов…` — у организации уже N других активных заданий (`ORG_ACTIVE_JOBS`, по умолчанию 3) |
| 400 | `Бесплатная проба закончилась…` / `На бесплатной пробе осталось N документов…` — на тарифе `free` остатка не хватает на оставшиеся строки |
| 401 | Нет токена или сессии |
| 404 | `Задание не найдено` — нет такого или оно чужой организации |
| 503 | `Очередь заданий сейчас недоступна, выпуск не начат. Ничего не списано — попробуйте ещё раз через минуту.` — задание при этом снова закрывается как `failed` |

## Пример

```bash
curl -X POST "https://vruchay.ru/api/jobs/$JOB_ID/resume" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN"
```
