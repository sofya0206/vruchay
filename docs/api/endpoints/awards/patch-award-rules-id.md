# PATCH /api/award-rules/{id}

Меняет набор правил. Поля необязательные: передавайте только то, что правите, но хотя бы одно поле — пустое тело отклоняется.

Правила заменяются целиком. Если в теле есть `rules`, все прежние правила набора удаляются и создаются заново из присланного списка, а `position` берётся из порядка в массиве. Точечной правки одного правила нет и не будет: порядок правил — это их приоритет, он меняется при перетаскивании любого правила, и присылать перенумерацию половины списка пришлось бы всё равно. Если `rules` в теле нет — правила не трогаются, меняются только названия и колонки.

При `isDefault: true` признак «по умолчанию» снимается со всех остальных наборов организации. Всё выполняется одной транзакцией.

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `id` | UUID (путь) | да | Идентификатор набора правил |

Тело — те же поля, что у `POST /api/award-rules`, все необязательные, но не пустой объект:

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `name` | string | нет | 1–200 символов после обрезки пробелов |
| `groupColumn` | string | нет | имя колонки группировки или `""` |
| `statusColumn` | string | нет | имя колонки статуса или `""` |
| `isDefault` | boolean | нет | признак «по умолчанию» |
| `rules` | Rule[] | нет | до 50 правил; присланный список заменяет прежние целиком |

Структура правила и условий — в [reference/award-rules.md](../../reference/award-rules.md).

```json
{
  "name": "Награждение по протоколу — 2026",
  "rules": [
    {
      "id": "1c7b2e3f-2222-4b6c-9d0e-1f2a3b4c5d6e",
      "label": "Победители",
      "conditions": [{ "field": "place", "op": "placeEquals", "value": 1, "withinGroup": true }],
      "action": "issue",
      "outputs": [
        { "templateDocumentId": "3a9e0c4d-3333-4c7d-8e1f-2a3b4c5d6e7f", "label": "Диплом победителя" },
        { "templateDocumentId": "5c1e2f60-6666-4e9f-8a12-5d6e7f809123", "subjectColumn": "coach", "dedupeScope": "group", "label": "Благодарность тренеру" }
      ]
    }
  ]
}
```

## Ответ

`200 OK` — набор после правки, контракт `AwardRuleSet` (см. [reference/award-rules.md](../../reference/award-rules.md)).

## Ошибки

| Код | Когда |
|---|---|
| 400 | `Некорректный идентификатор` — `id` не UUID |
| 400 | `Нечего обновлять` — тело без единого поля |
| 400 | `Введите название набора`, `Выберите колонку`, `Некорректное имя колонки`, `Выберите шаблон`, `Добавьте хотя бы одно значение`, `Начало интервала больше конца` и прочие сообщения схемы — как у `POST /api/award-rules` |
| 400 | `Выбранный шаблон недоступен: он удалён или лежит в корзине` |
| 401 | Нет токена или сессии |
| 404 | `Набор правил не найден` |
| 413 | Тело больше 1 МБ |

## Пример

```bash
curl -X PATCH "https://vruchay.ru/api/award-rules/$RULE_SET_ID" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Награждение по протоколу — 2026","isDefault":true}'
```
