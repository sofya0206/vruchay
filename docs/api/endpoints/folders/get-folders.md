# GET /api/folders

Папки организации в том порядке, в каком они стоят в колонке кабинета. Папка — плоский список: вложенности нет, папки внутри папки не бывает. Материал лежит либо в одной папке, либо в корне.

## Запрос

Параметров нет.

## Ответ

`200 OK` — массив папок.

| Поле | Тип | Описание |
|---|---|---|
| id | string (UUID) | Идентификатор папки. |
| name | string | Название, как его завела организация. |
| position | number | Порядок в колонке; меньше — выше. |
| count | number | Сколько живых материалов внутри. Удалённые в архив не считаются. |

```json
[
  { "id": "9f1c0c8e-0f3c-4a1a-9c1f-1f7d2a3b4c5d", "name": "Обучение", "position": 0, "count": 12 }
]
```

## Ошибки

| Код | Когда |
|---|---|
| 401 | Нет токена или cookie-сессии. |

## Пример

```bash
curl "https://vruchay.ru/api/folders" -H "Authorization: Bearer $TOKEN"
```
