# DELETE /api/mail/domains/{id}

Удаляет домен вместе со всеми отправителями на нём (каскадно). У шаблонов писем, где такой отправитель был указан, поле `senderId` обнуляется — дальше письма по этим шаблонам пойдут с отправителя по умолчанию: с другого подтверждённого домена организации, если он есть, иначе с общего адреса сервиса.

Отдельного эндпоинта для удаления одного отправителя нет — только вместе с доменом.

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| id | string (UUID) | да | Идентификатор домена |

Тела нет.

## Ответ

`200 OK`

| Поле | Тип | Описание |
|---|---|---|
| ok | boolean | Всегда `true` |

```json
{ "ok": true }
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | `id` не UUID: «Некорректный идентификатор» |
| 401 | Нет токена или сессии |
| 403 | Роль `member`: «Недостаточно прав для этого действия» |
| 404 | Домена нет или он чужой: «Домен не найден» |

## Пример

```bash
curl -X DELETE "https://vruchay.ru/api/mail/domains/$DOMAIN_ID" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN"
```
