# POST /api/mail/send/{documentId}

Ставит в очередь письма о выдаче документа всем отмеченным (`checked`) строкам таблицы получателей материала. Используется транзакционный шаблон из `POST /api/mail/templates/{documentId}` — без него отправка отклоняется. Ответ приходит сразу после постановки в очередь; сама отправка асинхронная: воркер делает до 5 попыток с нарастающей задержкой (первая — 15 с), состояние каждого письма видно в `GET /api/mail/emails?documentId=…` или `GET /api/mailing/log`.

Кому письмо не ставится — возвращается в `skipped` с причиной: нет адреса в строке, адрес некорректен, или шаблон требует вложение, а файл по строке ещё не выпущен. Если у шаблона нет своего отправителя (письма идут с общего адреса сервиса), перед постановкой проверяется лимит общего домена: не больше `SHARED_DOMAIN_BATCH_LIMIT` (по умолчанию 300) писем за раз и `SHARED_DOMAIN_DAILY_LIMIT` (по умолчанию 500) за сутки на организацию. Со своего подтверждённого домена лимита нет.

Действие необратимое и пишется в журнал аудита (`mail.send`). Защиты от повторного запуска здесь нет: второй вызов подряд попадёт на уникальный индекс «одно живое письмо на адрес и поток по материалу», и вся транзакция откатится с ошибкой 500 — для повторов и ручных списков используйте `POST /api/mailing/send`, где дубли пропускаются.

## Запрос

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| documentId | string (UUID) | да | Материал |

Тела нет.

## Ответ

`201 Created`

| Поле | Тип | Описание |
|---|---|---|
| queued | number | Сколько писем поставлено в очередь |
| skipped | array | Кому не поставлено: `{name, reason}` |

```json
{
  "queued": 47,
  "skipped": [
    { "name": "Иванов Пётр", "reason": "нет адреса" },
    { "name": "Сидорова Анна", "reason": "некорректный адрес «anna@»" },
    { "name": "Кузнецов Олег", "reason": "документ ещё не создан" }
  ]
}
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | `documentId` не UUID: «Некорректный идентификатор» |
| 400 | Шаблона нет: «Сначала сохраните письмо» |
| 400 | Отправитель шаблона удалён: «Отправитель не найден» |
| 400 | Домен отправителя перестал быть подтверждённым: «Домен example.ru не подтверждён — отправка невозможна» |
| 400 | Ни своего отправителя, ни общего адреса сервиса: «Отправка писем не настроена — обратитесь в поддержку» |
| 400 | Превышен разовый лимит общего домена: «За один раз с общего адреса уходит не больше 300 писем, а отмечено 350. Разбейте на несколько рассылок или подключите свой домен в настройках — со своего домена ограничения нет.» |
| 400 | Превышен суточный лимит общего домена: «За сутки с общего адреса уходит не больше 500 писем: сегодня уже отправлено 480, осталось 20. Подключите свой домен в настройках — со своего домена ограничения нет, и письма вызывают больше доверия.» |
| 401 | Нет токена или сессии |
| 500 | Кому-то из списка письмо этого потока по этому материалу уже стоит в очереди или ушло — нарушение уникального индекса не перехватывается |

## Пример

```bash
curl -X POST "https://vruchay.ru/api/mail/send/$DOCUMENT_ID" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN"
```
