# POST /api/tokens

Выдаёт новый токен API организации. Полный токен возвращается **только в этом ответе** — сервер хранит лишь его хеш (sha256), восстановить или показать повторно его нельзя. Потеряли — отзовите и выдайте новый.

Формат токена: `vru_` и 43 символа base64url (32 случайных байта). Токен не истекает сам; действует, пока его не отозвали через `DELETE /api/tokens/{id}`. У организации не может быть больше десяти действующих токенов одновременно.

Роль токена определяет, что ему можно: `member` работает с материалами, `admin` вдобавок удаляет. Управлять сотрудниками и токенами не может ни один токен (HumansOnlyGuard). Выдача записывается в журнал действий событием `token.create`.

**По токену API недоступно, только из кабинета (cookie-сессия).**

## Запрос

Тело (`application/json`):

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| name | string | да | Название токена: 1–100 знаков после обрезки пробелов. |
| role | string | нет | `member` или `admin`. По умолчанию `member`. |

```json
{
  "name": "выгрузка из CRM",
  "role": "member"
}
```

## Ответ

`201 Created`

| Поле | Тип | Описание |
|---|---|---|
| id | string (UUID) | Идентификатор токена — нужен для отзыва. |
| name | string | Название. |
| token | string | Полный токен. Показывается один раз. |

```json
{
  "id": "5f1c2e6a-9d0b-4c3e-8a7f-1b2c3d4e5f60",
  "name": "выгрузка из CRM",
  "token": "vru_XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX"
}
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | Пустое `name`: «Назовите токен — потом не разберётесь». |
| 400 | `name` длиннее 100 знаков или `role` не из списка `member`/`admin` — стандартное сообщение Zod в `errors[].message`. |
| 400 | Уже десять действующих токенов: «Больше десяти действующих токенов не бывает. Отзовите ненужные.» |
| 401 | Нет cookie-сессии. `{"statusCode":401,"message":"Требуется вход в систему","error":"Unauthorized"}` |
| 403 | Запрос пришёл по токену API: «Это действие доступно только человеку, вошедшему в кабинет. Токен API управлять сотрудниками не может.» |
| 403 | Роль `member`: «Недостаточно прав для этого действия». |
| 413 | Тело больше 1 МБ. |

## Пример

```bash
curl -X POST "https://vruchay.ru/api/tokens" \
  -b cookies.txt \
  -H "Content-Type: application/json" \
  -d '{"name":"выгрузка из CRM","role":"member"}'
```
