# PATCH /api/org

Меняет название организации. Название стоит в имени отправителя писем участникам, в приглашении друга и на витрине отзывов — то есть говорит от лица всей организации, поэтому право есть только у владельца и управляющего. Пробелы по краям обрезаются.

## Запрос

Тело (`application/json`):

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| name | string | да | Новое название: от 2 до 200 знаков после обрезки пробелов. |

```json
{
  "name": "Учебный центр «Развитие»"
}
```

## Ответ

`200 OK`

| Поле | Тип | Описание |
|---|---|---|
| ok | boolean | Всегда `true`. |

```json
{ "ok": true }
```

## Ошибки

| Код | Когда |
|---|---|
| 400 | Короче двух знаков: «Название не может быть короче двух букв». Длиннее 200 или не строка — стандартное сообщение Zod. |
| 401 | Нет действующего токена и нет cookie-сессии. `{"statusCode":401,"message":"Требуется вход в систему","error":"Unauthorized"}` |
| 403 | Роль `member` (в том числе токен с ролью `member`): «Недостаточно прав для этого действия». |
| 413 | Тело больше 1 МБ. |

## Пример

```bash
curl -X PATCH "https://vruchay.ru/api/org" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Учебный центр «Развитие»"}'
```
