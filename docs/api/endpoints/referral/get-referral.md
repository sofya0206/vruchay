# GET /api/referral

Всё, что показывает раздел «Пригласить друга»: код приглашения организации,
готовая ссылка, готовый текст для мессенджера, список приглашённых и сколько
бонусных документов уже заработано.

Раздел открыт любому сотруднику организации: звать коллег из соседней организации
будет тот, кто с ними знаком, а не обязательно владелец учётной записи.

Первый вызов имеет побочное действие: если у организации ещё нет кода
приглашения, он выдаётся именно здесь и закрепляется навсегда. Дальше запрос
только читает.

Начисленное нигде не хранится, а считается по фактам при каждом запросе: сколько
приглашённых организаций выпустили свои первые документы. Приглашённая считается
работающей, когда выпустила не меньше `qualifyDocuments` документов — просто
регистрации мало, иначе бонусы зарабатывались бы заведением пустых организаций.
Вознаграждение платится не больше чем за `maxRewarded` приглашённых.

Бонусные документы прибавляются к бесплатной пробе; сколько их сейчас
и сколько израсходовано, показывает `GET /api/org/usage`.

## Запрос

Параметров нет.

## Ответ

`200 OK`

| Поле | Тип | Описание |
|---|---|---|
| code | string | Код приглашения организации: 6 знаков из алфавита без похожих друг на друга (`0`/`o`, `1`/`l`/`i` в нём нет) — код диктуют по телефону. |
| link | string | Готовая ссылка на регистрацию: `<публичный адрес>/register?ref=<code>`. |
| message | string | Готовый текст приглашения для мессенджера — с названием организации и ссылкой. Собирается на сервере, чтобы человеку не пришлось придумывать его самому. |
| invitedTotal | number | Сколько организаций зарегистрировалось по ссылке. |
| invitedWorking | number | Сколько из них выпустили не меньше `qualifyDocuments` документов. |
| bonusEarned | number | Заработано бонусных документов: `min(invitedWorking, maxRewarded) × rewardPerFriend`. |
| welcomeBonus | number | Сколько документов получает пришедший по ссылке (`REFERRAL_WELCOME_BONUS`, по умолчанию 50). |
| rewardPerFriend | number | Сколько документов даётся за одного заработавшего приглашённого (`REFERRAL_REWARD`, по умолчанию 50). |
| qualifyDocuments | number | Сколько документов должен выпустить приглашённый, чтобы считаться работающим (`REFERRAL_QUALIFY_DOCUMENTS`, по умолчанию 10). |
| maxRewarded | number | За скольких приглашённых максимум платится вознаграждение (`REFERRAL_MAX_REWARDED`, по умолчанию 20). |
| invited | array | Приглашённые организации, старые первыми. |

Элемент `invited`:

| Поле | Тип | Описание |
|---|---|---|
| name | string | Название приглашённой организации. |
| joinedAt | string (ISO 8601) | Когда зарегистрировалась. |
| working | boolean | Выпустила ли она не меньше `qualifyDocuments` документов. |

```json
{
  "code": "k7m2qp",
  "link": "https://vruchay.ru/register?ref=k7m2qp",
  "message": "Мы в «Учебный центр «Развитие»» выдаём грамоты и сертификаты через сервис «Вручай»: загружаешь список участников — он сам делает именные файлы и рассылает их по почте. Вручную это занимало два дня, теперь — полчаса.\n\nВот приглашение, по нему дают 100 бесплатных документов вместо 50:\nhttps://vruchay.ru/register?ref=k7m2qp",
  "invitedTotal": 3,
  "invitedWorking": 2,
  "bonusEarned": 100,
  "welcomeBonus": 50,
  "rewardPerFriend": 50,
  "qualifyDocuments": 10,
  "maxRewarded": 20,
  "invited": [
    {
      "name": "СШОР «Олимп»",
      "joinedAt": "2026-04-02T07:15:00.000Z",
      "working": true
    },
    {
      "name": "Гимназия № 3",
      "joinedAt": "2026-05-11T13:44:20.000Z",
      "working": false
    }
  ]

```

Название приглашённой организации видно целиком — она сама зарегистрировалась
по вашей ссылке. Ни её адресов, ни идентификаторов, ни того, что именно она
выпускает, в ответе нет.

## Ошибки

| Код | Когда |
|---|---|
| 401 | Нет действующего токена и нет cookie-сессии. |
| 500 | Не удалось выдать код приглашения при первом вызове: десять сгенерированных кодов подряд оказались заняты. Случай крайне редкий, помогает повтор запроса. |

## Пример

```bash
curl "https://vruchay.ru/api/referral" \
  -H "Authorization: Bearer $VRUCHAY_TOKEN"
```

Что обещано по этому коду пришедшему — `GET /api/referral-offer?ref=<code>`,
он открыт без входа.
