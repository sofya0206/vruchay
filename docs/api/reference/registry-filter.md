# Отбор в реестре выданного

Один и тот же набор параметров принимают `GET /api/registry`,
`GET /api/registry/analytics`, `GET /api/registry/export.csv`,
`GET /api/registry/archive` (строкой запроса) и `POST /api/registry/revoke`,
`POST /api/registry/revoke/preview` (объектом `filter` в теле). Условие
выборки одно на всех (`apps/server/src/registry/registry-filter.ts`), поэтому
таблица, сводка, выгрузка и архив по одному отбору всегда содержат одни и те же
документы.

Схема — `registryFilterSchema` в `apps/server/src/registry/registry.dto.ts`.
Все параметры необязательны.

| Параметр | Тип | Описание |
|---|---|---|
| `search` | string, до 200 знаков | Поиск по имени и адресу почты получателя («содержит», без учёта регистра). Если строка целиком — UUID или короткий проверочный код (в любом написании: строчные, без дефисов, `O` вместо нуля), ищется точное совпадение по коду. |
| `documentId` | UUID | Материал, по макету которого выпущен документ. Ошибка: «Некорректный идентификатор материала». |
| `event` | string, до 200 знаков | Мероприятие — точное совпадение со строкой `eventName` в карточке материала. Значения берите из `GET /api/registry/facets`. |
| `state` | `valid` \| `revoked` \| `replaced` \| `expired` | Состояние документа. Ошибка: «Неизвестное состояние документа». |
| `mail` | `none` \| `queued` \| `sent` \| `delivered` \| `opened` \| `bounced` \| `failed` | Состояние письма. `none` — писем не было. Остальные значения — «есть хотя бы одно письмо в таком состоянии», а не «последнее письмо в таком состоянии»: у тех, кому переотправляли, отбор может разойтись с колонкой `mail` в строке. Ошибка: «Неизвестное состояние письма». |
| `from` | дата (`YYYY-MM-DD` или ISO 8601) | Начало периода выпуска, включительно. Ошибка: «Не удалось разобрать дату начала периода». |
| `to` | дата | Конец периода выпуска, включительно: «по 31-е» означает всё 31-е число целиком. Ошибка: «Не удалось разобрать дату конца периода». |

Границы периода считаются по календарным дням Москвы (UTC+3): дата
`2026-08-01` в `from` означает `2026-07-31T21:00:00Z`.

Всегда, независимо от параметров, выбираются только выпущенные документы
текущей организации (`kind = generated`), не удалённые и с загруженным файлом.
Документы материалов, лежащих в корзине, в реестре остаются — у них заполнено
поле `retention`.
