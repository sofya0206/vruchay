# Реквизиты продавца — шаблон

Скопируйте этот файл в `requisites.md` и заполните реальными значениями.
`requisites.md` внесён в `.gitignore` и в репозиторий не попадает: расчётный счёт
и банковские данные не должны уезжать на GitHub вместе с кодом, даже в приватный репозиторий.

Значения из `requisites.md` подставляются в: договор оферты, счета и акты, страницу
«Реквизиты» на сайте (её адрес требуется при подключении ЮKassa), договор-поручение
на обработку персональных данных.
