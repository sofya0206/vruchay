# Коммерческое предложение: «Вручай» для Всероссийской федерации лёгкой атлетики

**Вручай** — сервис массовой генерации именных наградных документов: грамот,
дипломов, сертификатов — для организаций, которые проводят соревнования и
мероприятия с большим числом участников.

## Проблема

Существующие на рынке сервисы (в частности, ГрамотаДел Express) отправляют
письма с документами через зарубежную инфраструктуру — например, через
американский Postmark. Для федерации, работающей с персональными данными
десятков тысяч участников по всей России, это означает трансграничную передачу
персональных данных за пределы РФ: риск по 152-ФЗ и осложнения на этапе
юридической и закупочной проверки.

## Решение

«Вручай» построен для российского рынка с учётом требований 152-ФЗ с нуля:

- **Инфраструктура в России.** Сервер, база данных и хранилище размещены в
  дата-центрах АО «Селектел» на территории РФ; почта отправляется через
  российский сервис DashaMail. Трансграничная передача данных не
  осуществляется.
- **Договор-поручение на обработку персональных данных** отдельным документом
  — с чётким распределением ответственности между оператором (федерацией) и
  обработчиком (сервисом), сроками уничтожения данных и реакции на инциденты.
- **Размещение на облачной платформе, аттестованной по требованиям ФСТЭК.**
  Сервер уже переведён в аттестованную зону Selectel; перенос хранилища
  завершается — точный статус на дату переговоров см. в Приложении № 3 к
  договору.
- **Уведомление оператора персональных данных в Роскомнадзор** — оформляется
  до начала обработки данных настоящих участников.
- **Публичная страница проверки подлинности документа по QR-коду** — участник
  или организатор в любой момент могут убедиться, что документ выдан именно
  вашей организацией.
- **Отправка с собственного домена федерации**, импорт протоколов
  соревнований, автоматическое распределение наград по занятым местам.
- **Договор с российским юридическим лицом (ИП) и закрывающие документы** —
  счета и акты для бухгалтерии без сюрпризов.

## Предлагаемые условия

Тариф **«Максимум»**: до 60 000 именных документов в год, неограниченное число
пользователей личного кабинета, импорт протоколов, приоритетная поддержка —
**149 000 ₽ за год** (без НДС — Лицензиар применяет УСН). Это стартовая
позиция для переговоров; точные условия — Приложение № 1 к Лицензионному
договору № 1.
