# Как подключить выдачу документов к форме на Тильде

Инструкция для заказчика. Программировать не нужно — всё делается
копированием двух строк и настройкой полей формы.

**Сколько займёт:** 20 минут.
**Что получится:** участник заполняет форму на вашем сайте, получает на почту
код подтверждения, вводит его — и ему приходит именной документ.

---

## Что происходит с точки зрения участника

1. Заполняет форму на вашей странице и нажимает кнопку.
2. Видит окно: «Мы отправили код на вашу почту».
3. Вводит код из письма.
4. Получает документ письмом, а также может скачать его сразу.

Код нужен не для формальности: без него любой человек мог бы выписать
документ на чужой адрес. Подтверждение адреса — единственное, что этому мешает.

---

## Шаг 1. Создайте интеграцию в кабинете

1. Войдите в кабинет «Вручай» → **Настройки** → **Интеграции**
2. Нажмите **«Новая интеграция»** и заполните:

| Поле | Что указать |
|---|---|
| Название | любое, для себя: «Форма семинара по плаванию» |
| Разрешённые сайты | адрес вашей страницы без `https://`, например `sca-swimming.com` |
| Документы | отметьте те, которые эта форма имеет право выдавать |
| Подтверждение адреса | **кодом на почту** (рекомендуется) |
| Один документ на адрес | включено |
| Окно скачивания | 60 минут |

> **Про «разрешённые сайты».** Это не формальность, а защита: запрос
> с чужого сайта сервис отклонит. Без этого вашу форму можно было бы
> скопировать на посторонний сайт и выписывать документы от вашего имени.
> Указывайте все домены, откуда форма реально работает, включая `www`.

3. Сохраните. В карточке интеграции появятся **две строки** —
   они понадобятся на следующем шаге.

---

## Шаг 2. Вставьте две строки в страницу Тильды

1. Откройте страницу в редакторе Тильды
2. **Настройки страницы** → **Ещё** → **HTML-код для вставки внутрь HEAD**
3. Вставьте обе строки из карточки интеграции. Выглядят они так:

```html
<link rel="stylesheet" href="https://vruchay.ru/api/v1/tilda-css/ВАШ-ТОКЕН">
<script src="https://vruchay.ru/api/v1/tilda-js/ВАШ-ТОКЕН"></script>
```

4. Сохраните и **опубликуйте** страницу

> Пользуйтесь кнопкой «Копировать» в карточке — токен подставится сам.
> Не дописывайте косую черту в конце адреса: с ней получится другой адрес,
> и скрипт не загрузится.
>
> Публикация обязательна: в режиме предпросмотра Тильда вставки в HEAD
> не применяет, и форма будет работать по-старому.

---

## Шаг 3. Настройте поля формы

Откройте форму на странице → **Контент** → список полей.

**Обязательные поля:**

| Имя переменной | Тип | Зачем |
|---|---|---|
| `email` | Почта | адрес, куда придёт документ |
| `doc_id` | Скрытое поле | какой документ выдавать |
| `consent` | Флажок | согласие на обработку данных |

**Поля с данными для документа** — по одному на каждую переменную макета.
Если в макете стоит `%name`, поле должно называться `name`:

| Имя переменной | Что подставится |
|---|---|
| `name` | вместо `%name` — фамилия и имя |
| `club` | вместо `%club` — название клуба |
| `place` | вместо `%place` — занятое место |

**Правило именования:** только латинские буквы, цифры и подчёркивание,
первая — буква. `name`, `club_name`, `place2` — годятся.
`Имя`, `2place`, `club-name` — нет: поле молча не подставится.

### Скрытое поле doc_id

1. Добавьте поле типа **«Скрытое поле»** (Hidden)
2. Имя переменной: `doc_id`
3. Значение: в карточке интеграции есть блок **«Значение скрытого поля
   `doc_id` в форме»** — там перечислены документы этой интеграции
   и их идентификаторы. Нажмите «Копировать» у нужного и вставьте сюда

### Флажок согласия

1. Добавьте поле типа **«Чекбокс»**
2. Имя переменной: `consent`
3. Сделайте его **обязательным**
4. Текст рядом с флажком — примерно такой:

```
Я согласен(на) на обработку персональных данных в целях изготовления
и отправки мне наградного документа. Согласие можно отозвать в любой момент.
Политика обработки данных: https://vruchay.ru/privacy
```

> Без отмеченного флажка форма не отправится — так и задумано.
> Согласие фиксируется вместе с текстом, который человек видел: если
> потом текст изменится, останется доказательство, на что он соглашался.

### Необязательно: согласие на рассылку

Отдельный флажок с именем `consent_marketing`. **Отдельный — не тот же самый.**
Согласие на выдачу документа и согласие на рассылку по закону смешивать нельзя.

---

## Шаг 4. Проверьте

Откройте опубликованную страницу и отправьте форму на свой адрес.

Должно произойти: появится окно с просьбой ввести код → код придёт
на почту за несколько секунд → после ввода придёт письмо с документом.

**Если ничего не происходит:**

| Что видите | В чём дело |
|---|---|
| Форма отправляется как обычно, окно не появляется | страница не опубликована, либо строки вставлены не в HEAD |
| «Запрос с этого сайта не разрешён» | домен не указан в «разрешённых сайтах» — проверьте `www` |
| «Документ недоступен» | документ не отмечен в интеграции |
| Код не приходит | посмотрите в «Спам»; если пусто — напишите нам |
| В документе пусто вместо имени | имя поля не совпадает с переменной макета либо не латиницей |

---

## Что важно знать

**Повторная отправка.** Если участник заполнит форму второй раз с тем же
адресом, новый документ не создастся — придёт ссылка на уже выданный.
Так задумано: иначе один человек мог бы наплодить себе документов.

**Ограничения.** На случай перебора включены ограничения по частоте
обращений и суточный предел выдач. Обычному участнику они не мешают.

**Кто отвечает за данные.** Оператором персональных данных участников
являетесь вы: вы решаете, кого награждать и какие сведения печатать.
Сервис обрабатывает эти данные по вашему поручению и в своих целях
не использует. Подробнее — в политике: https://vruchay.ru/privacy
