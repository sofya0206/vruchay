# Установка сервиса на сервер: подробная инструкция

Написано для человека, который не программист. Ничего знать заранее не нужно.

**Сколько займёт:** около часа, из них 20 минут ждать сборку.
**Что уже готово:** сервер куплен и настроен, домен `vruchay.ru` привязан,
ключ доступа создан.
**Что делаем:** создаём хранилище, вписываем пять паролей, запускаем сервис.

---

## Как пользоваться этой инструкцией

Команды выглядят вот так:

```bash
echo привет
```

**Что с ними делать:** открыть программу **Терминал** и вставить туда команду
целиком, затем нажать Enter.

Терминал открывается так: нажмите `Cmd + Пробел`, наберите `Терминал`,
нажмите Enter. Откроется окно с текстом — это нормально, так и должно быть.

Вставлять — `Cmd + V`, как везде. Копировать из инструкции — обычным
выделением или кнопкой копирования у блока.

**Если команда «зависла»** и ничего не происходит — обычно она работает.
Сборка идёт 20 минут молча, это нормально. Не закрывайте окно.

## Шаг 1. Создать хранилище (10 минут, мышкой)

Здесь будут лежать фоны грамот и готовые документы. На самом сервере им
места мало, поэтому файлы хранятся отдельно.

1. Откройте [панель Selectel](https://my.selectel.ru), войдите
2. Слева в меню найдите **«Объектное хранилище»** (или «S3»)
3. Нажмите **«Создать контейнер»**
4. Заполните:
   - **Имя:** `vruchay-prod`
   - **Тип:** приватный
   - **Зона:** ru-1
5. Создайте **второй контейнер** так же, но с именем `vruchay-backups`

Теперь нужны пароли к хранилищу:

6. В разделе хранилища найдите **«Пользователи»** или **«Сервисные пользователи»**
7. Нажмите **«Создать пользователя»**, имя — `vruchay-app`
8. Дайте ему доступ к контейнеру `vruchay-prod`
9. **Скопируйте показанные ключи в блокнот** — их покажут один раз

Ключей будет два: длинный «Access Key» и ещё длиннее «Secret Key».

> **Почему два контейнера и два пользователя.** Ключ от `vruchay-prod` будет
> лежать на сервере. Если сервер когда-нибудь взломают, злоумышленник получит
> этот ключ — и удалит файлы. Резервные копии в отдельном контейнере с
> отдельным ключом переживут такой день. Для копий пользователя создадим
> позже, когда будем их настраивать.

## Шаг 2. Взять пароли от почты (5 минут)

Сервис отправляет письма с документами через DashaMail.

1. Войдите в [DashaMail](https://dashamail.ru)
2. Найдите раздел **«Настройки»** → **«SMTP»** (или «Транзакционные письма»)
3. Скопируйте в блокнот **логин** и **пароль SMTP** — это не тот пароль,
   которым вы входите на сайт, а отдельный
4. Там же, в разделе про подключение своего домена, найдите строку для
   записи **SPF** — она выглядит примерно как `spf.dashamail.ru`.
   Скопируйте только эту часть, без `v=spf1` и `~all`

Если чего-то не находите — напишите в поддержку DashaMail: «Нужны данные
SMTP для транзакционных писем и значение для записи SPF».

## Шаг 3. Вписать пароли в файл (5 минут)

Откройте файл настроек:

```bash
open -e "/Volumes/T7 Shield/Проект вручай /gramota/docs/business/generated/prod.env"
```

Откроется обычный текстовый редактор. Найдите пять строк со словом
`ЗАПОЛНИТЬ` и замените его на значения из блокнота:

| Строка в файле | Что вставить |
|---|---|
| `S3_ACCESS_KEY=ЗАПОЛНИТЬ` | Access Key из шага 1 |
| `S3_SECRET_KEY=ЗАПОЛНИТЬ` | Secret Key из шага 1 |
| `SMTP_USER=ЗАПОЛНИТЬ` | логин SMTP из шага 2 |
| `SMTP_PASSWORD=ЗАПОЛНИТЬ` | пароль SMTP из шага 2 |
| `SMTP_SPF_INCLUDE=ЗАПОЛНИТЬ` | строка SPF из шага 2 |

**Важно:** слово `ЗАПОЛНИТЬ` замените целиком, знак `=` оставьте, пробелов
вокруг него не ставьте. Должно получиться так:

```
S3_ACCESS_KEY=a1b2c3d4e5f6
```

Сохраните файл: `Cmd + S`, закройте окно.

## Шаг 4. Отправить всё на сервер (2 минуты)

Три команды подряд. Вставляйте по одной, дожидаясь окончания.

**Первая** — отправляет файл с паролями:

```bash
cd "/Volumes/T7 Shield/Проект вручай /gramota" && scp -i ~/.ssh/vruchay docs/business/generated/prod.env vruchay@89.223.29.14:/opt/vruchay/.env
```

**Вторая** — отправляет сам сервис (займёт минуту, побежит список файлов):

```bash
cd "/Volumes/T7 Shield/Проект вручай /gramota" && rsync -az --exclude node_modules --exclude dist -e "ssh -i ~/.ssh/vruchay" ./ vruchay@89.223.29.14:/opt/vruchay/src/
```

**Третья** — закрывает файл с паролями от посторонних:

```bash
ssh -i ~/.ssh/vruchay vruchay@89.223.29.14 'chmod 600 /opt/vruchay/.env && echo "файл закрыт"'
```

Должно ответить `файл закрыт`.

## Шаг 5. Запустить сервис (20 минут ожидания)

```bash
ssh -i ~/.ssh/vruchay vruchay@89.223.29.14 'cd /opt/vruchay/src && ./scripts/server-deploy.sh'
```

Дальше окно будет долго показывать строки про сборку. **Это нормально.**
Не закрывайте его.

Что происходит внутри: сервер скачивает браузер Chromium — тот самый,
который потом печатает грамоты в PDF, — и собирает из исходников готовое
приложение.

**Признак успеха** — в конце появится:

```
  api: running
  worker: running
  web: running
  ✓ приложение отвечает
```

**Если появилась ошибка** — скопируйте последние 30 строк и покажите мне.
Разберу и скажу, что поправить.

## Шаг 6. Создать вашу учётную запись (1 минута)

Замените в команде почту, пароль и название организации на свои.
Пароль придумайте длинный, не короче 10 знаков.

```bash
ssh -i ~/.ssh/vruchay vruchay@89.223.29.14 "cd /opt/vruchay && docker compose -f docker-compose.prod.yml run --rm -e OWNER_EMAIL='ваша@почта.ру' -e OWNER_PASSWORD='придуманный-пароль' -e ORG_NAME='Ассоциация тренеров' api node dist/cli.js create-owner"
```

Должно ответить: `Создана организация «...», владелец ...`

---

## Шаг 7. Проверить, что всё работает

```bash
cd "/Volumes/T7 Shield/Проект вручай /gramota" && ./scripts/smoke.sh https://vruchay.ru
```

Все строки должны быть с галочкой ✓.

**Если пишет, что сайт недоступен** — подождите. Защищённое соединение
(замочек в браузере) сервер получает сам, но для этого адрес `vruchay.ru`
должен «разойтись» по интернету. Это занимает от 15 минут до двух суток.

Проверить, дошёл ли адрес:

```bash
dig +short vruchay.ru
```

Должно показать `89.223.29.14`. Если пусто — ещё не дошло, подождите.

Когда всё сойдётся — откройте [vruchay.ru](https://vruchay.ru) в браузере.
Вы увидите свою посадочную страницу, а по кнопке «Войти» — кабинет.

## Что делать, если что-то пошло не так

**Забыли, на каком шаге остановились** — все команды можно выполнять
повторно, они не ломают уже сделанное.

**«Permission denied» или «отказано в доступе»** — проблема с ключом.
Проверьте: `ls -l ~/.ssh/vruchay` — должно быть `-rw-------`.

**«Connection refused» или «не удалось подключиться»** — сервер
перезагружается или выключен. Посмотрите в панели Selectel, что он ACTIVE.

**Место на диске кончилось** — во время сборки такое бывает. Освободить:

```bash
ssh -i ~/.ssh/vruchay vruchay@89.223.29.14 'docker system prune -af && df -h /'
```

**Любая другая ошибка** — скопируйте текст ошибки целиком и покажите мне.
Не пытайтесь чинить наугад: сервер сейчас пустой, испортить нечего,
но время потеряется.

## После установки: три обязательных дела

1. **Уведомление в Роскомнадзор** — до первого реального участника.
   Без него штраф ИП от 100 тысяч рублей.
2. **Резервные копии** — [docs/launch-day.md](launch-day.md), шаг 8.
   Пока их нет, любой сбой означает потерю всего.
3. **Проверка восстановления из копии** — копия, которую ни разу
   не разворачивали, это предположение, а не копия.
