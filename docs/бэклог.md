# Бэклог — идеи на потом

Что не сделано и не в ближайшем плане. Ближайший план — в Obsidian у Сони.

## Редактор и кабинет
- Превью документа в списке, папки и перетаскивание
- Размер листа; предупреждение, если бланк не совпадает с листом
- Меню «три точки» у документа, предпросмотр перед выпуском
- Панель вставки вместо кнопки «Текст», богаче свойства текста
- Кнопка «Создать» — к вкладкам, а не в таблицу

## Продукт
- Виджет «сертификат одной кнопкой» для страниц курсов (GetCourse и т.п.)
- Telegram-бот, словоформы
- Федерации: импорт протокола соревнования → награждение по местам → пакет документов
- Отзывы: модель есть, форм нет — собирать пока не у кого
- MCP-сервер поверх API — когда попросит хотя бы один клиент

## Долги в коде
- Отдельный ключ S3 для резервных копий (сейчас пишет ключ приложения)
- Отдельный rate-limit для API-токенов
